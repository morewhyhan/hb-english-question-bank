湖北专升本英语 · 50 套模拟卷的题库与题型研究。

## 内容

| 目录 | 内容 |
|---|---|
| `00_原卷PDF/` | 三套机构模拟卷原卷（小蓝书 25 / 知本 15 / 慧航 10）与 2024—2026 真题原文 |
| `01_原文文本/` | 50 套卷子的逐页读图转写（419 页）与真题原文 |
| `02_六大题型/` | 按真题 11 类题型归好的题库（1—6 真题型，7—11 模拟卷特有） |
| `03_逐题研究/` | 11 份十层研究稿（每题：题面→候选→验算→干扰→意图→边界→错误→规则→模型→自检） |
| `04_解题模型/` | 待建 |
| `_提示词/` | PDF 转 Markdown 的智能体提示词 |
