#### 第 21 题　客户投诉 / 质量管理

**1）题面事实**
- 空位：表格第 21 行两个括号，左对「客户投诉」，右对「质量管理」。
- 提示形式：纯中文名词短语（定语＋中心名词），无首字母、无词性提示；备选 16 项（A—Q），Examples 已占用 G、E 两个字母。
- 诱导信号：表内「投诉」有四落点——F Customer complaint、J Complaint tracking、G Complaint handling process（示例）、L Customer feedback；「管理」有两落点——M Quality management、K Customer experience management。

**2）候选空间**
- 左空三类：①同词族（complaint 系）F / J / G；②同修饰语（customer 系）L / K / E；③主题相邻 B Product feature（「产品」与「客户」同为被服务对象）。
- 右空三类：①同中心词（management 系）M / K；②同修饰语（quality 系）A Quality assurance；③同场制度类 C Risk assessment、H Business rules。
- 无动词短语项可填：本表 16 项全是名词短语，故左空只需在名词短语内收敛。

**3）逐项验算**
- 左·F：customer＝客户、complaint＝投诉，两个词素一一对应，无余无缺，中文中心词「投诉」＝head noun complaint → **成立**。
- 左·J：complaint 对，但 tracking＝跟踪，中文没有「跟踪」这一语素，英文多出一个词素；且 J 是第 24 题「投诉跟踪」的唯一落点，一字母只能用一次 → 排除。
- 左·G：多出 handling（处理）、process（流程）两个词素，只有中文为「投诉处理流程」时才成立；G 又是示例字母 → 双重排除。
- 左·L：feedback＝反馈，中心词不是 complaint；「投诉」是行为，feedback 是回传的信息 → 排除。
- 左·K：中心词是 management（管理），修饰语是 customer experience（客户体验），中文中心词是「投诉」，三层修饰语全错位 → 排除。
- 右·M：quality＝质量、management＝管理，等量对应 → **成立**。
- 右·A：assurance＝保证，「保证」与「管理」在中文里也是两个词，不能互换 → 排除（A 留给第 23 题）。
- 右·K：management 这一层对得上，但 quality 被换成了 customer experience；这正是「见『管理』就选 K」的坑 → 排除。
- 右·C：assessment＝评估，与「管理」不同义 → 排除。
- 结论：21＝（F）（M）。

**4）干扰项设计**
出题人做了三件事：①把 K 放在 M 的同一列附近，让「管理」出现第二个落点，且 K 的 head noun 完全正确，只在修饰语上错；②把 complaint 系的三个项（F/J/G）摊在同一张表，让「投诉」出现四个落点，靠差异词素分胜负；③用示例 G 做减法陷阱——没先划掉示例字母的人，会把「投诉处理流程」当成「客户投诉」。

**5）命题意图**
考的不是背词表，而是「中文中心词→英文 head noun」的定位能力，外加「修饰语必须等量」的纪律。区分两类人：整表扫读、按印象配对的（会栽在 J 或 K）；先切中文语素、再逐词对齐的（30 秒内出答案）。

**6）判别边界**
- 中文若是「客户投诉处理」→ G（handling 有落点）；若是「投诉率」→ 表内无对应项，不能硬凑 J。
- 「质量保证」与「质量管理」的分界是 assurance / management，不是中文「保证/管理」的字面近似；两条都在表内时，只能各归其位。
- 与词库完形不同：本题只看名词短语的等值，不看它在句中作主/宾/定；与翻译填空不同：不要求产出英文，只要求辨认。
- 反例边界：若表内同时有 Customer complaint 与 Customer complaints，单复数不作判据（R9），仍按词素等量取。

**7）错误类型**
- 错 A：「投诉」→complaint，然后在 F/J/G 里随手取一个（多取 J）。错因：只匹配半个词，不检查差异词素 tracking。
- 错 B：「管理」→ 直接选 K。错因：只看中心词，不看修饰语；把「客户体验管理」当成「质量管理」的上位词。
- 错 C：选 G。错因：没把 Examples 的字母划掉，把示例当备选。

**8）可迁移规则**
- if 中文可切成「修饰语＋中心名词」，且表内有 ≥2 项共享同一词根 then 逐字对齐，**差异词素必须在中文有落点**，无落点者排除（R1＋R3）。
- if 某字母已在 Examples 出现 then 先划掉，不参与候选（R5）。
- 适用条件：两空都是「修饰语＋中心名词」的名词短语，且同一词根在表内占 ≥2 岗（complaint 系 F/J/G、management 系 M/K），逐字对齐才有意义。
- 例外：中文若本身是英文缩写或行业惯称（「质量保证」直接说 QA），词素对齐失效，改按表内英文全称取（R11）；表内若同现 complaint / complaints，单复数不作判据（R9）。

**9）模型位置**
04 → 术语匹配 → S2 同词族辨析 → R3。与 R6（主题场排除）冲突时 **R3 优先**：本表 16 项全属客服场，主题场无法区分任何一项，只能靠差异词素。与 R5 的关系：R5 是前置减法，先于一切规则执行。

**10）自检清单**
- 中文最后一个名词是不是「投诉」「管理」？英文对应项的 head noun 是否同词？
- tracking / handling / experience 三个差异词素，在中文里各自有没有落点？
- G、E 两个示例字母划掉了吗？

#### 第 22 题　退货政策 / 风险评估

**1）题面事实**
- 空位：第 22 行两括号；左「退货政策」，右「风险评估」。
- 提示：左空中心词是「政策」，右空中心词是「评估」；本表制度类项集中在 G/H/P 三项，评估类只有 C、A 两项。
- 诱导信号：P Return policy 与 H Business rules 都像「规定」；C Risk assessment 与 A Quality assurance 都以 -ss- 结尾，字形相近。

**2）候选空间**
- 左空：①同中心词（policy/rules/process 三个制度名词）P / H / G；②同修饰语（return 系）只有 P；③主题相邻 D Added value（退货常与「附加值」同现）。
- 右空：①同场（风险/质量）C / A；②同中心词（-ment / -ance 抽象名词）M / A；③主题相邻 H Business rules（风控常写作 rule）。

**3）逐项验算**
- 左·P：return＝退货、policy＝政策，等量 → **成立**。
- 左·H：business＝商业、rules＝规则；中文「退货」在英文里没有落点，只剩「规则≈政策」的近似 → 排除；H 还要留给第 25 题。
- 左·G：complaint handling process，多出 complaint / handling 两词素，且示例占用 → 排除。
- 左·D：added value＝附加值，「退货」无落点 → 排除。
- 右·C：risk＝风险、assessment＝评估，等量 → **成立**。
- 右·A：quality assurance＝质量保证，assurance 是「保证」不是「评估」，且 quality 无「风险」义；A 留给第 23 题 → 排除。
- 右·M：management＝管理，中文是「评估」→ 排除。
- 右·H：rules＝规则，中文是「评估」→ 排除。
- 结论：22＝（P）（C）。

**4）干扰项设计**
①用 policy / rules / process 三个「制度类」名词制造中文近义（政策≈规定≈流程），逼学生回到英文原词；②把 A（assurance）放在 C（assessment）的视觉附近，两个词只差 -ur- / -ess-，扫读型学生会把「评估」配给 assurance；③D Added value 是「退货场景」的语义联想陷阱（退货常涉及附加值），但中文根本没这两个字。

**5）命题意图**
考「抽象名词后缀辨义」：-ance（assurance 保证）／-ment（assessment 评估、management 管理）／-cy（policy 政策）。区分靠后缀与搭配记词的人，和靠中文近义联想的人。

**6）判别边界**
- 「退货规定」若出现，仍选 P（policy 可译「规定/政策」）；「退货流程」表内无（只有投诉处理流程 G），不能借 G。
- 「风险评估」≠「风险管理」（risk management，表内无）；若表中同时有二者，按「评估＝assessment、管理＝management」分。
- 与第 23 题的分界：22 右考「评估」，23 右考「保证」，两题共用 A/C 这一对形近项，必须交叉校验（A 只能用一次）。

**7）错误类型**
- 错 A：见「政策」选 H。错因：把 rules 的中文「规则」扩写成「政策」，忽略 business≠return。
- 错 B：见「评估」被 assurance 的 -ss- 字形吸走选 A。错因：以形近代替义辨。
- 错 C：把 22 右与 23 右都填 A（或都填 C）。错因：不做「一字母一用」的互斥校验。

**8）可迁移规则**
- if 两个选项形近（assurance / assessment）then 必须回到后缀义（-ance 表性质/保证，-ment 表行为/结果）并核中文中心词（R4）。
- if 中文中心词是「政策/规定/流程」then 优先在 policy / rules / process 三项内比，看修饰语是否等量（R2）。
- 适用条件：中文中心词是制度类或抽象名词（政策/评估），且表内并置形近项（assurance / assessment）或近义制度项（policy / rules / process）时才启用。
- 例外：policy 在商务语境可译「保单」，中文若是「保险单」仍选 P；若表内另有 risk management，中文写「风险管理」须改选 management 项，不套「评估」（改按 R2）。

**9）模型位置**
04 → 术语匹配 → S3 近义中文区分 → R4；与 R3 的执行顺序：先 R3（同词根逐字对齐），再 R4（异词根近义辨形），因为同词根项更容易被误判为「都对」。与第 23 题构成**对照对**，必须同表呈现。

**10）自检清单**
- 左空中心词是「政策」还是「规则」？英文 head noun 是 policy 还是 rules？
- C 与 A 的后缀各是什么？中文要的是「评估」还是「保证」？
- A、C 是否已被别题占用？

#### 第 23 题　产品特征 / 质量保证

**1）题面事实**
- 空位：第 23 行两括号；左「产品特征」，右「质量保证」。
- 提示：左空中心词「特征」（feature），右空中心词「保证」（assurance）；本表含 quality 的项有两个（A、M），含 product/commodity 的项有两个（B、Q）。
- 诱导信号：D Added value（附加值）在语义上是「产品卖点」，与「特征」同场；Q Commodity code 用 commodity 冒充 product。

**2）候选空间**
- 左空：①同场「卖点」类 B / D；②同「商品/产品」义 B / Q；③同品质域 A / M（学生易把「特征」当「质量特征」）。
- 右空：①同修饰语 quality A / M；②同后缀 -ance / -ment 抽象名词 A / C；③同场制度类 H。

**3）逐项验算**
- 左·B：product＝产品、feature＝特征，等量 → **成立**。
- 左·D：added value＝附加值，value≠特征；「附加值」是价值增量，不是可观察的属性 → 排除。
- 左·Q：commodity＝商品、code＝代码；中文无「代码」，且 commodity 指大宗商品，与 product 不同 → 排除（Q 留给第 24 题）。
- 左·A：quality assurance 整个短语里没有「产品/特征」 → 排除。
- 右·A：quality＝质量、assurance＝保证，等量 → **成立**。
- 右·M：management＝管理≠保证；若右空选 M，则第 21 题右「质量管理」无解，互斥校验立刻报警 → 排除。
- 右·C：assessment＝评估≠保证 → 排除。
- 结论：23＝（B）（A）。

**4）干扰项设计**
①本卷把 quality 拆成 A / M 两项，分别锁在 23 右与 21 右，制造「同修饰语跨题分配」，逼学生做全局互斥；②用 D Added value 承接「产品卖点」的语义联想；③用 Q Commodity code 的 commodity 冒充 product，且 code 与「特征」毫无关系，属「半词匹配」陷阱。

**5）命题意图**
考「一字母一用」的全局约束下的分配能力：单题看 A、M 都含 quality，只有把 21、23 两题放在一起看，才能确定谁归谁。区分逐题作答的人与先做全局分配的人。

**6）判别边界**
- 「产品代码」若出现 → Q（但那是 commodity code 的宽松译法，本卷无此项）。
- 「产品附加值」→ D；「产品特征」→ B。三者是同一语义场里的三个不同名词，靠中心词分。
- 质量保证（A）与质量管理（M）不可互换：assurance 面向「对外承诺」，management 面向「内部过程」。
- 与第 21 题构成对照：21 右若填 A，23 右就无解；这类「跨题互斥」是本题型特有的边界。

**7）错误类型**
- 错 A：「特征」→ 联想到「卖点」选 D。错因：用语义联想代替词素对齐。
- 错 B：「商品」→ product 选 B（而 B 已用于「产品特征」）。错因：commodity / product 不分。
- 错 C：21 右与 23 右都填 M 或都填 A。错因：不做互斥校验，把「同修饰语」当成「同义」。

**8）可迁移规则**
- if 两个选项共享同一修饰语（quality）then 先看中文中心词（管理/保证）分配，再用「一字母一用」反向校验（R2＋R10）。
- if 中文中心词是抽象属性（特征/价值/代码）then 只认英文 head noun（feature / value / code），修饰语不构成判据（R1）。
- 适用条件：两空共享同一修饰语（quality 见于 A、M），或中文中心词是抽象属性（特征/价值/代码）时，先定 head noun 再分配字母。
- 例外：feature 在 IT 语境可译「功能」，中文写「产品功能」仍选 B；若 21 右已占 M，本题的 A/M 分配不能再靠修饰语，须改按 R10 互斥校验。

**9）模型位置**
04 → 术语匹配 → S1 复合名词短语 → R2（中心词定位）＋R10（互斥校验）。与 R3 的关系：本题不靠同词根，而靠「同修饰语不同中心词」，属 R2 的典型场；与 R5 无冲突（A、B 均非示例）。

**10）自检清单**
- 左空中心词是「特征」，英文 head noun 是不是 feature？
- quality 出现两次（A、M），21 右与 23 右是否各得其一？
- D 的 value 与「特征」有没有语义落点？

#### 第 24 题　投诉跟踪 / 商品代码

**1）题面事实**
- 空位：第 24 行两括号；左「投诉跟踪」，右「商品代码」。
- 提示：左空中心词「跟踪」（tracking），右空中心词「代码」（code）；本表带 -ing 的项只有 J、G，带 code 的只有 Q。
- 诱导信号：G（示例）与 J 同含 complaint；B Product feature 的 product 与「商品」近义；本卷外的 postal code（卷10）会跨卷干扰。

**2）候选空间**
- 左空：①同词族 J / G（示例）/ F（已被 21 占用）；②同「流程」义 G；③主题相邻 L Customer feedback（跟踪常与反馈同现）。
- 右空：①唯一 code 项 Q；②同「商品」义 B / Q；③同「编号」义 H（rules 被误读为「规则编号」）。

**3）逐项验算**
- 左·J：complaint＝投诉、tracking＝跟踪，等量 → **成立**。
- 左·G：多出 handling / process；且示例占用 → 排除。
- 左·F：complaint 对，但中文多出「跟踪」而英文无 tracking；F 已用于 21 → 双重排除。
- 左·L：feedback＝反馈，与「跟踪」不同 → 排除。
- 右·Q：commodity＝商品、code＝代码，等量 → **成立**。
- 右·B：product feature，feature≠代码 → 排除（B 已用于 23）。
- 右·H：business rules，无「代码」义 → 排除。
- 结论：24＝（J）（Q）。

**4）干扰项设计**
①21 与 24 共用 complaint 词族，把 F 与 J 拆到两题，让学生在两题之间来回改；②G 是示例，制造「看起来最完整」的假候选（complaint handling process 比 complaint tracking 更像「投诉」）；③「商品」用 commodity，而表内另有 product（B），考 commodity/product 之别；④跨卷干扰：卷10 有 postal code，学生若把「code＝邮政」带进来会找不到落点。

**5）命题意图**
考「同一词族在两题间的分配」＋「commodity 与 product 的语义差」。区分能全局排布 16 个字母的人，和逐题现找的人。

**6）判别边界**
- 「投诉处理」→ G（示例，本卷不可选）；「投诉跟踪」→ J；「投诉」→ F。三者按差异词素分。
- 「商品」＝commodity（可交易的大宗/货物），「产品」＝product（生产物）；中文写「商品」时优先 Q 而非 B。
- 与第 21 题的分界：21 左是纯「投诉」，24 左多一个「跟踪」语素。

**7）错误类型**
- 错 A：21 左与 24 左都填 F（或都填 J）。错因：没意识到同一字母只能用一次，两题共用词族时不做分配。
- 错 B：选 G。错因：把示例当备选，且被「投诉处理流程」的完整感吸引。
- 错 C：「商品」→ product 选 B。错因：commodity / product 不分。

**8）可迁移规则**
- if 两题共享同一词族 then 先列该族的全部字母，按差异词素一一指派，再回填（R3＋R10）。
- if 中文是「商品」而非「产品」then 优先 commodity，不看 product（R11）。
- 适用条件：同一词族在表内占 ≥2 岗（complaint 系 F/J/G），或中文是「商品」而非「产品」（commodity / product 对立）时才启用。
- 例外：commodity code 在物流语境也译「商品编码」，中文写「编码」仍选 Q；若表内另给 product code，中文「产品代码」须改选后者（R11 精确项优先）。

**9）模型位置**
04 → 术语匹配 → S2 同词族辨析 → R3，挂在 R10（互斥校验）之下执行，因为本题的判据是「两题如何分配」而非单词辨义。与 R6 冲突：本表全属客服场，R6 无效。

**10）自检清单**

**4）干扰项设计**

**5）命题意图**

**9）模型位置**
04 → 术语匹配 → S1 复合名词短语 → R2；与 R4 并联（修饰语相同、中心词近义时启用语义场四分）。优先级：R2 先定位中心词，R4 再在中心词同义的残余项间裁决。

**10）自检清单**

- 中文要的是「反馈」还是「体验/参与」？

#### 第 21 题　保价邮件 / 中国邮政

**1）题面事实** 左空中心词「邮件」，右空是机构名「中国邮政」；表内「邮件」类有 C insured mail、Q registered mail 两项，机构名只有 E 一项（A 是「快递公司」，已作示例）。
**2）候选空间** 左：①同类邮件 C/Q；②同含 express 的服务 D/B；③同「保」义（insured/registered 都表「附加保障」）。右：①机构 E；②公司 A（示例）；③服务名 B/D。
**3）逐项验算**
- 左·C：insured＝保价、mail＝邮件，等量 → **成立**。
- 左·Q：registered＝挂号，registered mail 是「挂号信」；挂号与保价是两种不同附加服务（挂号保「送达记录」，保价保「赔偿金额」），中文无「保价」落点 → 排除。
- 左·D：international express service 是「服务」，不是「邮件」这一实物类 → 范畴不符（R8），且多出 international/express 两词素 → 排除。
- 左·B：express service＝快递服务，无「邮件/保价」→ 排除。
- 右·E：China＝中国、Post＝邮政，等量 → **成立**。
- 右·A：courier services company＝快递公司，是商业机构，与「中国邮政」这一国营邮政主体不同；且 A 为示例 → 双重排除。
- 右·B：express service 是服务名，不能指称机构 → 排除。
- 结论：21＝（C）（E）。
**4）干扰项设计** ①把 Q（registered mail）与 C（insured mail）并排，两者都是「mail 前加过去分词」的同构项，只差词根；②右空放 A（示例）与 B（服务名）夹击 E，考「机构名≠服务名」；③E 用专名 China Post，学生若不认识专名会去 B/D 找「邮政快递」。
**5）命题意图** 考「同构复合名词靠词根辨义」（insured/registered）＋「机构/服务/实物三分」。区分按中文「保价」二字回英文找 insure 词根的人，与按「挂号也像保价」猜的人。
**6）判别边界** 若中文为「挂号信」→ Q；「保价信」→ C（本表 mail 统称邮件）。「中国邮政」是专名，不能用 the post office（表内无）。与第 23 题分界：23 考「国际＋服务」，本题考「邮件类型」。
**7）错误类型** ①见「保」选 Q（错因：把挂号当保价，两词中文都带「保障」色彩）；②右空选 A（错因：没划掉示例）；③右空选 B（错因：把服务名当机构）。
**8）可迁移规则** if 两个同构项只差过去分词词根（insured/registered）then 用中文中心词的动词义回推（保价→insure，挂号→register）（R3）；if 中文是机构名 then 只在专名/公司名项中选，服务名不算（R8）。
- 适用条件：两项同构、只差一个分词词根（insured / registered），或中文是机构专名（中国邮政）时，才按词根义与范畴判。
- 例外：中文写「挂号信」→ Q、「保价信」→ C，本表 mail 统称「邮件」；若中文是「保价包裹」，范畴已非 mail，须改按 R8 重判，不套本题。
**9）模型位置** 04 → 术语匹配 → S2 同词族辨析 → R3；与 R8（范畴一致）并联。冲突时 R8 优先于 R2：先排除「服务/实物」错范畴，再比中心词。

#### 第 23 题　国际快递服务 / 邮政编码

**1）题面事实** 左空中心词「服务」，且带限定语「国际」；右空中心词「编码」。表内 express service 有两项（B 无国际、D 有国际），code 只有 H，address 有 F。

- 左·D：international＝国际、express service＝快递服务，限定语与中心词都等量 → **成立**。
- 左·B：express service 中心词对，但中文多出「国际」这一语素，英文无 international 落点 → 排除（**限定语等量**是本卷最容易被忽略的一条）。
- 左·A：courier services company 是公司，不是服务；且示例占用 → 排除。
- 左·C：insured mail 是邮件类型，非服务 → 排除。
- 右·H：postal＝邮政、code＝编码，等量 → **成立**。
- 右·F：return address＝回复地址，address 是「地址」不是「编码」→ 排除（F 留给 25）。
- 右·O：letter box＝信箱，是设施不是编码 → 排除。
- 结论：23＝（D）（H）。
**4）干扰项设计** ①B/D 只差 international，专治「看到 express 就选」；②右空用 F（address）与 H（code）制造「地址/编码」同场混淆；③A 是示例，防止学生把「快递公司」当「快递服务」。
**5）命题意图** 考「限定语必须逐字兑现」——中文多一个字（国际），英文就必须多一个词。区分逐词对齐的人与整体印象配对的人。
**6）判别边界** 若中文是「快递服务」→ B；「快递公司」→ A（示例）；「国际快递公司」表内无。邮政编码＝postal code，不是 zip code（表内无）。
**7）错误类型** ①左空选 B（错因：漏看「国际」，限定语未兑现）；②右空选 F（错因：address/code 同属「地址信息」场）；③右空选 O（错因：见 postal 就选，不看中心词）。
**8）可迁移规则** if 中文含限定语（国际/自取/到付/纪念）then 英文必须在该位置有对应词，缺则排除（R1 的限定语版）；if 两项仅差一个限定语 then 该限定语就是唯一判据（R3）。
- 适用条件：中文含限定语（国际/自取/到付/纪念），且两项只差这一个限定语时，该限定语即唯一判据。
- 例外：中文若是「快递公司」而非「快递服务」，范畴转机构，须改按 R8 选公司名项；邮政编码只作 postal code，zip code 未列不得代填（R11）。
**9）模型位置** 04 → 术语匹配 → S1 复合名词短语 → R1（限定语等量）＋R3；与 R6 冲突时 R3 优先：本表全属邮政场，主题场无效。
**10）自检清单** 「国际」在英文里有没有落点？右空中心词是 code 还是 address？B 与 D 差在哪一个词？

#### 第 24 题　自取件 / 汇票

**1）题面事实** 左空中心词「件」（快件），带限定语「自取」；右空是金融票据「汇票」。表内以 express item 结尾的有 M（自取）、P（到付，示例）。
**2）候选空间** 左：①快件类 M/P（示例）；②包裹 N（已用 22）；③服务 D。右：①票据 J；②邮件 Q；③编码 H（已用 23）。
**3）逐项验算**
- 左·M：self pick-up＝自取、express item＝快件，等量 → **成立**。
- 左·P：freight collect＝到付（运费到付），是付费方式不是取件方式；且示例占用 → 排除。
- 左·N：postal parcel 已用于 22，中文无「自取」；且 parcel 是包裹不是「件」→ 排除。
- 左·D：international express service 是服务，非「件」→ 排除。
- 右·J：money＝汇款、order＝汇票/汇款单，等量 → **成立**。
- 右·Q：registered mail＝挂号信，是邮件不是票据 → 排除。
- 右·H：postal code 已用于 23，且无「汇」义 → 排除。
- 结论：24＝（M）（J）。
**4）干扰项设计** ①M 与 P 是「同尾不同头」的成对项（…express item），专治「见 express item 就选」；②右空用 Q（挂号）做「邮政金融业务」的近场干扰；③M 的 self pick-up 是合成限定语，需要拆成 self＋pick-up 两部分核。
**5）命题意图** 考「复合限定语拆解」（self / pick-up / freight / collect）＋「票据 vs 邮件」。区分拆词的人与抓尾词的人。
**6）判别边界** 「到付件」→ P（示例）；「自取件」→ M；「上门取件」表内无（那是 pick-up service）。汇票≠汇款（remittance），本表只有 money order。
**7）错误类型** ①左空选 P（错因：只看到 express item，未拆限定语）；②右空选 Q（错因：把「汇」联想到「邮政汇兑」后随手取邮件项）；③24 左与 22 左都填 N（错因：不做互斥校验）。
**8）可迁移规则** if 两项共享尾部名词 then 逐个拆解前部限定语，与中文限定语一一对应（R3＋R1）；if 中文是票据类 then 只在含 money/order/bill 的项中选（R8）。
- 适用条件：两项共享尾部名词（…件/…单），或中文属票据类（汇票/汇款单）时，先拆前部限定语，再按范畴取。
- 例外：汇票≠汇款（remittance），表内只有 money order 时不得用 remittance 项代（R11）；「上门取件」是 pick-up service，与「自取件」方向相反，不可共用一项（R8）。
**9）模型位置** 04 → 术语匹配 → S2 同词族辨析 → R3，叠加 R10 互斥校验（N 已在 22 用掉）。
**10）自检清单** 「自取」对应 self pick-up 还是 freight collect？右空是票据还是邮件？N 是否已被 22 占用？

#### 第 25 题　贺卡 / 回复地址

**1）题面事实** 左空「贺卡」是纸制品；右空「回复地址」是地址类。表内纸品类有 L、I、K（已用 22），地址类有 F、H（已用 23）、容器 O。
**2）候选空间** 左：①卡类 L；②印刷品 I；③邮票 K（已用）。右：①地址 F；②编码 H（已用）；③信箱 O。
**3）逐项验算**
- 左·L：greeting＝问候/贺、card＝卡，等量 → **成立**。
- 左·I：printed matter＝印刷品，是邮资分类，不指「贺卡」这一具体物品 → 排除。
- 左·K：commemorative stamp 已用于 22，且无「卡」义 → 排除。
- 左·J：money order 是票据 → 排除。
- 右·F：return＝回复/退回、address＝地址，等量 → **成立**。
- 右·O：letter box＝信箱，是容器，不是地址 → 排除（这是 letter 一词的陷阱）。
- 右·H：postal code 已用于 23，code≠address → 排除。
- 结论：25＝（L）（F）。
**4）干扰项设计** ①右空用 O（letter box）借「letter」制造「信件相关」错觉，考「容器≠地址」；②左空用 I（印刷品）考「资费类别≠具体物品」；③整卷五题把 17 个字母用到 10 个，剩 B/G/I/O/Q 五个「全未用」项，专供「剩余法」误用者填空。
**5）命题意图** 考「具体物品 / 资费类别 / 设施 / 编码」四类范畴的最后收敛，以及不被「剩余字母」诱导。区分按语义类别定位的人，与数「还剩哪几个字母」的人。
**6）判别边界** 「回邮信封」表内无；「退件」＝returned mail（表内无）。return address 指寄件人地址，不是「退货地址」（return 在此为「回寄」义）。
**7）错误类型** ①右空选 O（错因：letter 触发「信件」联想）；②左空选 I（错因：把贺卡归入印刷品资费类）；③用剩余法把未用字母（B/G/I/O/Q）硬塞进空格（错因：把「没用过」当成「该用」）。
**8）可迁移规则** if 中文是具体物品 then 排除资费类别项（printed matter）与设施项（letter box）（R8）；if 用剩余法 then 只作最后一轮校验，且必须能说出该字母与中文的词素对应（R10）。
- 适用条件：中文是具体物品或地址成分，且表内混有资费类别项（printed matter）与设施项（letter box）时，先按范畴排除再取剩余。
- 例外：return address 指寄件人地址，不是「退货地址」；若中文真写「退货地址」，须改按 R11 取 return 的「退货」义，本表无此义项则不得选；剩余法只作末轮校验（R10）。
**9）模型位置** 04 → 术语匹配 → S1 复合名词短语 → R2＋R8；与 R10 的关系：剩余法（R10 的弱形式）只在 5 题全做完后校验，不得用于首选。
**10）自检清单** 「贺卡」是物品还是资费类别？letter box 的中心词是 box 还是 address？剩下没用过的字母能不能说出词素对应？

**4）干扰项设计** ①左空四个硬件项并列，考「卡」这一中心字；②右空用 J（菜单）考「界面元素 vs 页面」；③N 的 sound 与 M 的 flat 都是形容词性修饰，需回到名词 card/screen。
**5）命题意图** 考「同一语义场（电脑部件/界面）内的中心字收敛」。区分按中文中心字回英文 head noun 的人。
**6）判别边界** 「声卡」≠「音响」（speaker，表内无）；「主页」≠「网站」（website，表内无）。home page 亦作 homepage，表内分写。
**7）错误类型** ①左空选 M（错因：把「卡」与「屏」都当硬件，未比中心字）；②右空选 J（错因：菜单/主页同属界面，未分「控件/页面」）；③23 左与 22 右都填 L（错因：不做互斥校验）。
**8）可迁移规则** if 中文中心字是「卡/盘/屏」then 英文 head noun 必为 card/disk/screen，修饰语不构成判据（R2）；if 中文是「页面」then 排除控件类（menu/icon）（R8）。

- 例外：home page 亦作 homepage，表内分写时以表内拼法为准；「网站」（website）与「主页」不同项，表内无 website 时不得用 home page 代（R11）。

**10）自检清单** 「卡」的英文 head noun 是 card 吗？J 为什么不能填右空？L 是否已在 22 用掉？

#### 第 24 题　上滚动 / 下拉式菜单

**1）题面事实** 左空「上滚动」带方向副词「上」；右空「下拉式菜单」带方向修饰「下拉式」。表内方向类有 G（up）、J（pull-down）、P（drag）。
**2）候选空间** 左：①滚动 G；②关闭 F；③点击 O（已用）。右：①菜单 J；②页面 I（已用）；③图标 P。
**3）逐项验算**
- 左·G：scroll＝滚动、up＝上，等量 → **成立**。
- 左·F：switch off＝关闭，与「滚动」无关 → 排除。
- 左·O：click on 已用于 22，无「滚动」义 → 排除。
- 左·P：drag the icon 是拖动，方向不明 → 排除。
- 右·J：pull-down＝下拉式、menu＝菜单，等量 → **成立**。
- 右·I：home page 已用于 23，无「菜单」义 → 排除。
- 右·P：drag the icon＝拖动图标，不是菜单 → 排除。

**4）干扰项设计** ①左空用 F（switch off）做「开关类动作」干扰，二者都是「动词＋副词」结构；②右空用 P（drag the icon）做「带宾语动作」干扰；③G 的 up 与 J 的 pull-down 都含方向义，考「方向词只修饰、不决定中心词」。
**5）命题意图** 考「动词＋副词」结构与「修饰语＋中心词」结构的分辨：左空是动作短语，右空是名词短语。

**7）错误类型** ①左空选 F（错因：把「关闭」当成「上下」的对立动作）；②右空选 P（错因：图标/菜单同属界面元素）；③左空选 O（错因：把「滚动」当成「点击」的一种）。

- 适用条件：中文含方向词（上/下/下拉），英文有对应副词或前缀（up / down / pull-down）时，方向词作校验、中心词作判据。

**9）模型位置** 04 → 术语匹配 → S4 动作短语（左）＋S1 名词短语（右）；两者同题出现时，先判词性再判词义。
**10）自检清单** 左空是动作还是名词？「上」对应 up 还是 down？右空中心词是 menu 吗？

#### 第 25 题　备份 / 操作系统

**1）题面事实** 左空「备份」是动作（也可作名词），右空「操作系统」是系统软件名。表内剩余动作 C、F，名词 D；K 为示例「重启」。
**2）候选空间** 左：①备份 C；②重启 K（示例）；③关闭 F。右：①系统 D；②分辨率 E（示例）；③网络 B（已用）。
**3）逐项验算**
- 左·C：back up＝备份，等量 → **成立**。
- 左·K：reboot＝重启，是「重新启动」不是「备份」；且 K 为示例 → 双重排除。
- 左·F：switch off＝关机，动作结果不同（备份不关机）→ 排除。
- 右·D：operating＝操作、system＝系统，等量 → **成立**。
- 右·E：high resolution＝高分辨率，是显示参数不是系统；且 E 为示例（原卷误印「高分频率」）→ 排除。
- 右·F：switch off 是动作，不能作系统名 → 排除。
- 结论：25＝（C）（D）。
**4）干扰项设计** ①左空用 K（示例「重启」）与 F（关闭）夹击 C，三者都是「对电脑的整体操作」；②右空用 E 的错译（高分频率）制造「参数 vs 系统」的混淆；③C 是「动词＋副词」结构（back up），与 F 同构，靠副词义（up＝完成/存起，off＝关闭）分。
**5）命题意图** 考「动词＋副词」短语的义辨（back up / switch off / log in / scroll up 四组同构），这是本卷的核心考点。区分按副词义推整体义的人。
**6）判别边界** 「备份」也可说 backup（名词，合写），表内分写为动词短语；「系统还原」表内无。K 虽为示例，但「重启」与「备份」在中文里都属「维护操作」，是本卷最接近的一对。
**7）错误类型** ①左空选 K（错因：没划掉示例，且「重启/备份」同属维护操作）；②左空选 F（错因：把「关闭」当成「保存退出」）；③右空选 E（错因：被错译「高分频率」带偏，把 E 当「高性能」类）。
**8）可迁移规则** if 中文是「动词＋结果」的操作 then 英文取「动词＋副词」短语，副词表结果（up＝完成/存起，off＝断开）（R4）；if 选项为示例 then 一律排除（R5）。
- 适用条件：中文是「动词＋结果」的操作（备份/关闭/启动），英文取「动词＋副词」短语、副词表结果（up＝完成、off＝断开）时启用。
- 例外：backup 合写是名词、分写是动词短语，中文若是名词「备份文件」，须改按 R8 取名词形；示例项一律先排除（R5）。
**9）模型位置** 04 → 术语匹配 → S4 动作短语 → R8＋R4；与 R5 的关系：示例排除先行。
**10）自检清单** back up 的 up 表什么？K 是不是示例？右空是软件名还是参数？

- 右·O：vocational program＝职业课程/项目，中文「教育」无落点 → 排除。
- 结论：24＝（N）（H）。
**4）干扰项设计** ①同一题左右两空共用 program，只能靠修饰语 video/educational 分配，是最干净的「修饰语定位」样本；②O 用 vocational 做「教育类」泛化干扰；③I（已用）作互斥校验。
**5）命题意图** 考「中心词相同、修饰语决定」的纯样本。学生若只记「program＝项目」，两空必乱。
**6）判别边界** 「教学项目」在中文里既可指 video program 也可指 educational program，此时以中文限定语「视频/教育」为准；「课件」＝courseware（表内无）。

- 适用条件：同题两空共享同一中心词（program），修饰语（video / educational）即唯一判据时启用。
- 例外：中文「教学项目」可两指，此时以限定语「视频/教育」为准（R2）；中文「课件」＝courseware，表内无则不得用 program 代（R11）。
**9）模型位置** 04 → 术语匹配 → S1 复合名词短语 → R2（修饰语版）。这是 04 里「同中心词对照对」的标准样例。
**10）自检清单** video 与 educational 各对应哪个中文限定语？左右空会不会填反？I 是否已用？

#### 第 25 题　理学学士 / 学分

**1）题面事实** 左空是学位名（Bachelor of Science），右空是学分（Credit）。表内学位类有 A、C，计量类只有 D。
**2）候选空间** 左：①理学学士 A；②学位 C（上位）；③研究生 E。右：①学分 D；②课程作业 J；③学期论文 K（示例）。

- 左·A：bachelor＝学士、of science＝理学，等量 → **成立**。

- 右·D：credit＝学分，等量 → **成立**。
- 右·J：course assignment＝课程作业，是任务不是计量 → 排除。
- 右·K：term paper＝学期论文，且为示例 → 排除。
- 结论：25＝（A）（D）。
**4）干扰项设计** ①左空用 C（上位概念）做「以大类代小类」的陷阱；②右空用 J/K 两个「课程产出物」干扰「学分」这一计量单位；③A 是唯一含 of 结构的三词术语，考「从右往左切」（Bachelor of Science＝理学+学士）。

- 例外：中文「文学学士」＝Bachelor of Arts，表内无则不得用 Bachelor of Science 代（R11）；「学位证书」是 degree certificate，不可拆字母拼（R10）。

#### 第 21 题　发动进攻 / 中立国

**1）题面事实** 左空是「动＋宾」结构（发动＋进攻），右空是「形＋名」结构（中立＋国）。表内动宾短语只有 D、E 两项（I 是名词短语），国家类只有 O。
**2）候选空间** 左：①动宾 D/E；②名词短语 I/G；③单动词 F。右：①国家 O；②基地 A；③能力 N。
**3）逐项验算**
- 左·D：launch＝发动、strikes＝打击/进攻，动宾等量 → **成立**。
- 左·I：all-out attack＝全面进攻，是名词短语，中文「发动」无落点 → 排除（留给 25）。
- 左·E：hit targets＝击中目标，动宾结构对但宾语是「目标」不是「进攻」→ 排除（留给 24）。
- 左·G：carpet bomb＝地毯式轰炸，无「发动」义 → 排除（留给 22）。
- 右·O：neutral＝中立、country＝国家，等量 → **成立**。
- 右·A：air base＝空军基地，是设施不是国家 → 排除。
- 右·N：military capabilities＝军事能力，抽象名词 → 排除。
- 结论：21＝（D）（O）。
**4）干扰项设计** ①左空放 I（all-out attack）——中文「全面进攻」与「发动进攻」只差一字，且都是进攻类，考「动宾 vs 名词」；②右空用 A（基地）与 N（能力）做「军事名词」泛化；③D 的 strikes 是复数名词，学生可能误当动词。
**5）命题意图** 考「结构类型先于词义」：中文是动宾，英文就必须是动宾。区分先判结构再辨义的人。
**6）判别边界** 「发动战争」＝launch a war（表内无）；「进攻」单独作名词＝attack（I 可作名词）。strike 单数可作名词「罢工」，复数 strikes 在军事语境才是「打击」。
**7）错误类型** ①左空选 I（错因：只比中文「进攻」二字，不看「发动」）；②左空选 E（错因：都是动宾，未比宾语）；③右空选 A（错因：基地/国家都属「地点」）。

- 例外：strike 单数可作名词「罢工」，复数 strikes 才在军事语境作「打击」；中文写「罢工」须改按 R11 换义；「进攻」单独作名词时 I 可作名词，不套动宾（R8 边界）。
**9）模型位置** 04 → 术语匹配 → S4 动宾短语 → R8；这是本文件里 R8 最典型的样本（中文结构直接可见）。

#### 第 25 题　全面进攻 / 撤军

**1）题面事实** 左空「全面」修饰「进攻」，右空「撤军」是单词。表内剩余未用项为 F、H、I、N；其中 I 是名词短语「全面进攻」，F 是「撤军」。
**2）候选空间** 左：①全面进攻 I；②发动 D（已用）；③军事集结 H。右：①撤军 F；②集结 H；③能力 N。
**3）逐项验算**
- 左·I：all-out＝全面、attack＝进攻，等量 → **成立**。
- 左·D：launch strikes 已用于 21，且多「发动」义 → 排除。
- 左·H：military buildup＝军事集结，是部署不是进攻 → 排除。
- 右·F：pullback＝撤军/撤回，等量 → **成立**。
- 右·H：military buildup 是「集结」（增兵），方向与「撤」相反 → 排除。
- 右·N：military capabilities＝军事能力 → 排除。
- 结论：25＝（I）（F）。
**4）干扰项设计** ①左空用 H（buildup）与 I 做「攻/守/集结」三向干扰；②右空用同一 H 做「增兵 vs 撤军」的反义陷阱；③整卷剩 H、N 两项完全未用，供「剩余法」误用者填空。
**5）命题意图** 考「方向义」（进攻/撤军/集结）与「动宾 vs 名词」。区分能判方向的人。
**6）判别边界** 「撤军」≠「撤退」（retreat 指战败后退，pullback 指有组织撤回）；「增兵」＝reinforce（表内无）。
**7）错误类型** ①右空选 H（错因：把「集结」当「撤军」，方向相反）；②左空选 D（错因：21 已用未校验，且未看「全面」）；③用剩余法把 N 塞进空格（错因：把「未用」当「该用」）。
**8）可迁移规则** if 中文含方向义（进攻/撤/集结）then 用方向对立的选项互验，反向项排除（R4）；if 只剩两个未用字母 then 仍须逐一验算，不得直接填（R10）。
- 适用条件：中文含方向义（进攻/撤/集结），且表内有方向对立项时，用对立项互验、反向项排除。
- 例外：中文「撤军」≠「撤退」——retreat 指战败后退、pullback 指有组织撤回，写「撤退」时须改取 retreat 项（R11）；只剩两个未用字母仍须逐一验算（R10）。
**9）模型位置** 04 → 术语匹配 → S4（名词短语）＋R4 方向辨义。
**10）自检清单** 「全面」对应 all-out 吗？H 的方向是增还是撤？N 为什么不行？

**10）自检清单** absolute 与 relative 各对什么？line 的中心词义？M 是否示例？

#### 第 22 题　年净收入 / 经济增长

**1）题面事实** 左空三层修饰（年/净/收入），右空「经济」修饰「增长」。表内 income 系有 A、H、L、N 四项。
**2）候选空间** 左：①年净收入 L；②人均可支配收入 H；③货币收入 A。右：①经济增长 Q；②收入再分配 N；③经济资源 C。
**3）逐项验算**
- 左·L：annual＝年、net＝净、income＝收入，三词全兑现 → **成立**。
- 左·H：per capita disposable income＝人均可支配收入，多出 per capita/disposable，缺 annual/net → 排除。
- 左·A：money income＝货币收入，无「年/净」→ 排除（留给 25）。
- 右·Q：economic＝经济、growth＝增长，等量 → **成立**。
- 右·N：income redistribution＝收入再分配，是分配不是增长 → 排除（留给 23）。
- 右·C：economic resources＝经济资源，中心词是 resources → 排除（留给 23）。
- 结论：22＝（L）（Q）。
**4）干扰项设计** ①四个 income 项（A/H/L/N）同表，考「限定语个数必须相等」；②H 是最长项，学生易被「人均可支配」的完整感吸引；③右空 C/N 都含 economic/income 词根。
**5）命题意图** 考「限定语逐层兑现」——中文有三层（年/净/收入），英文必须三层全有。区分数限定语的人。
**6）判别边界** 「总收入」＝total income（表内无）；「净收入」与「净产值」不同（后者 output value）。
**7）错误类型** ①左空选 H（错因：项最长最像「正式术语」）；②左空选 A（错因：income 字面命中）；③右空选 N（错因：收入/增长都属经济）。
**8）可迁移规则** if 中文限定语 ≥2 层 then 英文必须逐层有对应词，多一层或少一层都排除（R1）；同词根多岗时按限定语数量分配（R3）。
- 适用条件：中文限定语 ≥2 层（年＋净＋收入）时，英文须逐层有对应词，多一层或少一层都排除（R1）。
- 例外：中文「总收入」＝total income，表内无则不得用 net income 代（R11）；「净产值」是 output value，写「产值」须改选，不套「收入」。
**9）模型位置** 04 → 术语匹配 → S1 多层复合名词 → R1＋R7；这是 R7（切块）最典型的题。
**10）自检清单** 「年」「净」在英文有无落点？H 多了哪几个词？N 的中心词是什么？

#### 第 23 题　经济资源 / 收入再分配

**1）题面事实** 左空「经济」修饰「资源」，右空「收入」修饰「再分配」。表内 resources 有两项（C、D），income 系有 A、H、L（已用）、N。
**2）候选空间** 左：①经济资源 C；②资源配置 D；③经济增长 Q（已用）。右：①收入再分配 N；②年净收入 L（已用）；③货币收入 A。
**3）逐项验算**
- 左·C：economic＝经济、resources＝资源，等量 → **成立**。
- 左·D：proper allocation of resources＝资源的合理配置，中心词是 allocation（配置）不是 resources → 排除。
- 左·Q：economic growth 已用于 22 → 排除。
- 右·N：income＝收入、redistribution＝再分配，等量 → **成立**。
- 右·L：annual net income 已用 22，且无「再分配」→ 排除。
- 右·A：money income 无「再分配」→ 排除（留给 25）。
- 结论：23＝（C）（N）。
**4）干扰项设计** ①C/D 是「资源 vs 资源配置」对，D 含 resources 但中心词是 allocation；②右空三个 income 项，靠 redistribution 一词定胜负；③re- 前缀（再）是低频考点。
**5）命题意图** 考「of 结构中心词后置」（allocation of resources 的中心词是 allocation）与「re- 前缀」。
**6）判别边界** 「资源配置」若中文写作「资源分配」→ D；写作「经济资源」→ C。二者靠中心词分。
**7）错误类型** ①左空选 D（错因：见 resources 就选，不知 of 结构中心词在前）；②右空选 A（错因：income 字面命中）；③右空选 L（错因：22 已用未校验）。
**8）可迁移规则** if 术语为 A of B 结构 then 中心词是 A（allocation），B 只是修饰（R7）；if 中文含「再」then 英文须有 re- 前缀（R1）。
- 适用条件：术语为 A of B 结构时中心词是 A（allocation）；中文含「再」时英文须有 re- 前缀。
- 例外：中文写「资源配置」→ D、写「经济资源」→ C，靠中心词分（R2）；若「再分配」项缺 re-，须按 R1 判词素缺失，不拿 income distribution 硬凑。
**9）模型位置** 04 → 术语匹配 → S1 of 结构 → R7；与 R1 叠用。
**10）自检清单** allocation of resources 的中心词是哪个？「再」对应 re- 吗？A 留给哪一题？

#### 第 24 题　共同富裕 / 就业机会

**1）题面事实** 左空「共同」修饰「富裕」，右空「就业」修饰「机会」。表内 prosperity 只有 O，opportunity 只有 P。
**2）候选空间** 左：①共同富裕 O；②经济增长 Q（已用）；③扶贫资金 M（示例）。右：①就业机会 P；②家庭需求 B；③贫困人口 J。
**3）逐项验算**
- 左·O：shared＝共同/共享、prosperity＝富裕/繁荣，等量 → **成立**。
- 左·Q：economic growth 已用 22，且无「富裕」→ 排除。
- 左·M：poverty relief funds 是资金，且示例 → 排除。
- 右·P：job＝就业/工作、opportunity＝机会，等量 → **成立**。
- 右·B：family needs＝家庭需求，是需求不是机会 → 排除。
- 右·J：impoverished population 是人群 → 排除。
- 结论：24＝（O）（P）。
**4）干扰项设计** ①O 的 shared 是过去分词作定语（共享的），学生易误当「share（股份）」；②右空 B/J 都属扶贫语境词，考「语境相关≠词义对应」。
**5）命题意图** 考「分词定语」与「语境相关项排除」。区分按词素而非按主题联想的人。
**6）判别边界** 「共享经济」＝sharing economy（表内无）；「繁荣」＝prosperity，与「富裕」（wealth）近义但不同项。
**7）错误类型** ①左空选 Q（错因：经济类词泛化）；②左空选 M（错因：扶贫语境联想）；③右空选 B（错因：需求/机会都属「民生」）。
**8）可迁移规则** if 选项与主题高度相关但词素不对应 then 排除（R6 只作弱化，R1 才是判据）；if 定语是过去分词（shared）then 按「被共享的」理解（R11）。
- 适用条件：选项与主题高度相关但词素不对应时排除（R6 只弱化、R1 才是判据）；定语是过去分词（shared）时按「被共享的」理解。
- 例外：中文「共享经济」＝sharing economy，若表内只有 shared，须注意 shared≠sharing，不得用 shared 项（R11）；「繁荣」＝prosperity，与「富裕」近义不同项。
**9）模型位置** 04 → 术语匹配 → S1 分词定语 → R1；R6 在此显式失效（全表同为扶贫场）。
**10）自检清单** shared 是什么形式？opportunity 对应「机会」吗？语境相关的 B/M 为何不行？

#### 第 25 题　货币收入 / 国有企业

**1）题面事实** 左空「货币」修饰「收入」，右空「国有」修饰「企业」。表内剩余未用项为 A、B、E、G、H、J；A 对「货币收入」、E 对「国有企业」。
**2）候选空间** 左：①货币收入 A；②年净收入 L（已用）；③人均可支配收入 H。右：①国有企业 E；②家庭需求 B；③贫困人口 J。
**3）逐项验算**
- 左·A：money＝货币、income＝收入，等量 → **成立**。
- 左·H：per capita disposable income 多出三层修饰，且无「货币」→ 排除。
- 左·L：annual net income 已用 22 → 排除。
- 右·E：state-owned＝国有、enterprises＝企业，等量 → **成立**。
- 右·B：family needs 是需求 → 排除。
- 右·J：impoverished population 是人群 → 排除。
- 结论：25＝（A）（E）。
**4）干扰项设计** ①左空剩 A/H 两个 income 项，靠「货币」（money）一词分；②右空 E 是唯一含 enterprises 的项，其余全是 needs/population 等民生词；③state-owned 是复合形容词，需拆 state＋owned。
**5）命题意图** 考「复合形容词拆解」与「剩余项辨伪」。区分逐词核的人。
**6）判别边界** 「国有企业」亦作 state-owned company（表内用 enterprises）；「私营企业」＝private enterprises（表内无）。
**7）错误类型** ①左空选 H（错因：项长显得「正式」）；②右空选 B（错因：民生语境联想）；③把 state-owned 读成「国家拥有」后找不到对应（错因：不会拆复合形容词）。
**8）可迁移规则** if 定语是「名词＋-ed」（state-owned）then 按「被国家拥有的」译（R1）；剩余项仍须逐词核（R10）。
- 适用条件：定语是「名词＋-ed」（state-owned）时按「被国家拥有的」译；剩余项仍须逐词核（R10）。
- 例外：中文「国有企业」本表用 enterprises（亦作 company）；「私营企业」＝private enterprises，表内无则不得用 state-owned 项代（R11）。
**9）模型位置** 04 → 术语匹配 → S1 复合形容词 → R1。
**10）自检清单** money 对应「货币」吗？state-owned 怎么拆？B/J 为何不行？

#### 第 21 题　客户忠诚度 / 客户反馈

**1）题面事实** 左空「忠诚度」是程度名词，右空「反馈」是信息名词。表内 customer 系有 B（示例）、C、D、J、K、P 六项。

**3）逐项验算**
- 左·P：customer loyalty＝客户忠诚度，等量 → **成立**。
- 左·D：customer retention＝客户维系（留住客户的动作/比率），retention≠loyalty → 排除（留给 25）。

**4）干扰项设计** ①loyalty/retention 是客服领域最容易被当成同义的对照（忠诚是态度，维系是动作），中文「忠诚度/维系」其实分得清；②右空 J/K 都属「客户声音」类；③示例 B 占掉最顺手的 experience。
**5）命题意图** 考「态度名词 vs 行为名词」（loyalty/retention）。区分概念分得清的人。

**7）错误类型** ①左空选 D（错因：忠诚≈维系）；②右空选 J（错因：期望/反馈都属客户意见）；③右空选 B（错因：示例未划）。

#### 第 22 题　质量保证 / 服务承诺

**1）题面事实** 左空「质量」修饰「保证」，右空「服务」修饰「承诺」。表内 assurance 只有 Q，promise 只有 M，agreement 有 F。
**2）候选空间** 左：①质量保证 Q；②服务承诺 M；③SLA F。右：①服务承诺 M；②SLA F；③质量保证 Q（互斥）。
**3）逐项验算**
- 左·Q：quality＝质量、assurance＝保证，等量 → **成立**。
- 左·M：service promise＝服务承诺，修饰语与中心词错位 → 排除（右空要用）。
- 左·F：service level agreement＝服务级别协议，无「质量」→ 排除（留给 23）。

- 右·F：SLA 是「协议」（agreement），有法律约束力，与「承诺」（promise）不同 → 排除。
- 右·Q：quality assurance 已用于左空 → 互斥排除。
- 结论：22＝（Q）（M）。
**4）干扰项设计** ①promise/agreement 是客服合同语境的核心对照（承诺是单方表态，协议是双方约定）；②F 带缩写 (SLA)，学生易被缩写吓退或误当「服务承诺」；③左右两空互为干扰项，考互斥。
**5）命题意图** 考「单方承诺 vs 双方协议」的概念差，以及缩写的展开（Service Level Agreement）。
**6）判别边界** 「服务保证」＝service guarantee（表内无）；「服务标准」＝service standard（表内无）。
**7）错误类型** ①右空选 F（错因：SLA 常被口译成「服务承诺」）；②左右填反（错因：service/quality 未对位）；③左空选 M（错因：见 promise 就选）。
**8）可迁移规则** if 中文是「承诺」then 选 promise，不选 agreement（协议）（R4）；if 选项带括号缩写 then 先展开全称再判（R1）。

**9）模型位置** 04 → 术语匹配 → S3 概念对照 → R4；缩写展开归 R1。
**10）自检清单** SLA 展开是什么？promise 与 agreement 差在哪？左右会不会填反？

#### 第 23 题　品牌体验 / 服务级别协议

**1）题面事实** 左空「品牌」修饰「体验」，右空是「服务级别」修饰「协议」。表内 experience 有 B（示例）、L 两项；agreement 只有 F。
**2）候选空间** 左：①品牌体验 L；②客户体验 B（示例）；③客户期望 J。右：①SLA F；②服务承诺 M（已用）；③质量保证 Q（已用）。
**3）逐项验算**

- 例外：中文「气候异常」＝climate anomaly，表内无则不得用 climate change 代（R11）；change 与 warming 不可互换，写「变暖」须改取 warming（R4）。

**10）自检清单** change 与 warming 各对什么？J 是否示例？N 为什么不选？

**3）逐项验算**
- 左·C：alternative＝替代、energy sources＝能源，等量 → **成立**。

**4）干扰项设计** ①energy 三项（C/H/K）同词根，考「替代/可再生/效率」三分；②右空依赖 21 的互斥（F 已用）。

**6）判别边界** 「清洁能源」＝clean energy（表内无）；alternative 强调「可替代」，renewable 强调「可再生」，二者在政策文本中常并列但不等义。
**7）错误类型** ①左空选 K（错因：替代/可再生混）；②左空选 H（错因：见 energy 就选）；③右空选 F（错因：21 已用未校验）。

- 例外：中文「清洁能源」＝clean energy，表内无则不得用 alternative energy 代（R11）；alternative（可替代）与 renewable（可再生）常并列但不等义（R4）。
