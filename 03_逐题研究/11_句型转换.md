41. We allow students to use dictionary.（变被动）

Students ______ ______ to use dictionary.

> **答案：are allowed**（两空各一词；are = be 的现在时复数，allowed = allow 的过去分词）

**① 题面事实**

- 原句：We allow students to use dictionary.
- 指令：变被动。
- 空位：Students ______ ______ to use dictionary. 两个空，位于主语 Students 之后、to use dictionary 之前；空外只保留 Students / to use dictionary / 句号。
- 句法事实：SVO + O + to do（allow + 宾语 students + 不定式补足语）；allow 为一般现在时，主语 We 为第一人称复数；宾语 students 为复数。
- 提示形式：无括号词、无首字母；中文指令是唯一提示。
- 诱导信号：① Students 已是复数，容易只写 are 而漏分词；② allow 与原形同形，容易写成 are allow；③ 汉语“学生被允许使用字典”只有一个“被”，容易只加一个 be 或只把 allow 变 -ed；④ 空后 to use dictionary 被保留，容易误以为 to 也要改（allowed using / allowed use）；⑤ 原句 dictionary 无冠词、单数，容易顺手改成 a dictionary / dictionaries；⑥ 只有两个空，排除了 by us 和三词形式。
- 原卷核对：PDF 第 6 页；原句确为 dictionary（无冠词），不是转写漏字。

**② 候选空间**

这个位置理论上只能放被动谓语的前两段：be 的限定形式 + 过去分词。可能类别有：① be + V-ed（唯一合格类）；② be + 原形/现在分词（形态不全）；③ 单独 V-ed（缺 be）；④ V-ed + be（语序倒置）；⑤ 情态 + be + V-ed（语义/结构改变）；⑥ 换义动词的被动（词汇替换）；⑦ 主动形式（语态未变）。

| 候选 | 结构归属 | 错型标签 |
|---|---|---|
| are allowed | be(are) + V-ed | ✅ 目标 |
| were allowed | be(were) + V-ed | 时态错 |
| allowed | V-ed 单独作谓语 | 漏助动词 |
| allowed are | V-ed + be | 语序错 |
| are allow | be + 原形 | 形态错 |
| is allowed | be(is) + V-ed | 一致错 |
| are allowed use | be + V-ed + 动词原形 | 漏 to |
| are allowed to using | be + V-ed + to doing | 非谓语错 |
| are permitted | 换义动词的被动 | 换词 |
| are allowed to use a dictionary | 加冠词 | 空外改动 |

本题至少给出 9 种错写，覆盖时态错、语序错、漏助动词三类必测错型。

**③ 逐项验算**

- ✅ **are allowed**：Students are allowed to use dictionary. 主语是原句宾语 students；be 用 are 与复数一致；allowed 为 allow 的过去分词；to use dictionary 原样保留；时态仍为一般现在时。结构完整，意义不变，成立。
- ❌ **were allowed**（B 时态）：Students were allowed to use dictionary. 句子本身合语法，但原句 allow 是一般现在时，改写后成过去；原句没有过去时间参照，违反“保持原句时态”。不得分。
- ❌ **allowed**（A 漏助动词）：Students allowed to use dictionary. 限定谓语缺失；allowed 若读作过去式，主语 Students 反而成了“允许”的施事，与原句宾语角色冲突；to use 悬空。不成立。
- ❌ **allowed are**（A 语序）：Students allowed are to use dictionary. 作为被动谓语不成立：被动必须是 be + V-ed，allowed 不能先于 are。若把 allowed 硬读成后置定语（= students who are allowed），句子另有“获准的学生要使用……”之意，已不是原句的被动改写；且 are to use 变成“be to do”的计划义。
- ❌ **are allow**（A 形态）：Students are allow to use dictionary. be 后要求过去分词，allow 是原形；被动形态未完成。不成立。
- ❌ **is allowed**（A 一致）：Students is allowed to use dictionary. 主语 Students 为复数，be 必须用 are；违反主谓一致。不成立。
- ❌ **are allowed use**（A 补足语）：Students are allowed use dictionary. allow 的宾语补足语是不定式 to do；被动中 to 保留；allowed 后接裸动词不成立（区别于 make/let 被动补 to）。不成立。
- ❌ **are allowed to using**（A 非谓语）：Students are allowed to using dictionary. to 后要求动词原形；using 是动名词/现在分词；allow doing 只用于“allow + 动名词”作宾语（We don't allow smoking），不用于“allow sb doing”。不成立。
- ❌ **are permitted**（B 词汇）：Students are permitted to use dictionary. 语法成立，但 permitted 不是原句词；改写题不许换同义词，空位只要求形态变换。不得分。
- ❌ **are allowed to use a dictionary**（B 空外改动）：语法成立，但空外原词 dictionary 被改成 a dictionary；违反“空外冻结”。不得分。
- 结论：只有 **are allowed** 同时满足“被动形态完整 + 时态一致 + 主谓一致 + 补足语保留 + 空外不动”。

**④ 干扰项设计**

- 把 Students 放句首，制造“主语已给，只填 be”的错觉；两个空恰好是 be + V-ed，但学生容易只填一个词，或把 be 重复填进两个空（are are）。
- 保留 to use dictionary，把难点从“选词”转成“改多少、留多少”：改多了（to using / use）错，改少了（allowed）也错。
- allow 与原形同形，are allow 是最顺手的错；dictionary 的裸单数则是“顺手修复原句”的陷阱。
- 出题人没有给 by us 的空位；学生若补 by us，说明没看空数、也没理解泛指施事可省。

**⑤ 命题意图**

- 考被动语态的完整构成（be + V-ed）、be 的时态与数、以及 allow 类动词的 to 不定式在被动中的保留。
- 区分三类人：只会加 be 的人（are allow）；会变分词但漏 be 的人（allowed）；能同时管住形态、一致、补足语和空外成分的人（are allowed）。
- 为什么用这个句子：allow 是“to 保留”类的代表，与 make/let“to 复原”类形成对照；复数主语 + 现在时同时考一致与时态；保留的 to use dictionary 考“改写边界”。

**⑥ 判别边界**

- 与连词成句：连词成句给的是无序词块，词块全给，考“排序”；本题给完整句 + 指令 + 两空框架，考“按指令改形态”，空外不能动。连词成句里可以把 by us 放进去，本题没有这个空。
- 与翻译填空：翻译填空从汉语出发，可选 allow / permit / let 等不同词；本题原句已定 allow，只改语态，不许换词。
- 与改错：改错是“原句有错，找出来改”；本题原句除 dictionary 的裸单数瑕疵外没有错，是“按指令产生新形式”，不要把改写题做成改错题。
- allow 类 vs make/let 类：allow/ask/tell/expect/want + O + to do → 被动保留 to；make/let/have/see/hear + O + do → 被动补 to（He was made to work）。这是本题最重要的边界。
- allow doing vs allow sb to do：We don't allow smoking.（allow + 动名词作宾语）≠ We allow students to use...（allow + 宾语 + to do）。被动分别是 Smoking is not allowed. / Students are allowed to use...
- by 短语：施事泛指时可省；若要保留，放句末（... by us），但本题无空位，且 by us 多余。
- dictionary 裸单数：原卷瑕疵；自由写作应写 a dictionary / dictionaries；本题不改，改了反而错。

**⑦ 错误类型**

- 错 A 时态漂移（were allowed）：把“变被动”当成“换 be 形式”，忽略原句时态；汉语“被允许”无时态，负迁移。
- 错 B 漏助动词（allowed）：只知道把 allow 变 -ed，不知道被动还需要 be；汉语“被”只有一个字，不需要两个词。
- 错 C 语序倒置（allowed are）：知道要 be 和 V-ed，但把分词当形容词前置；或受“be + 表语”位置干扰。
- 错 D 形态不全（are allow）：只改 be，不改实义动词；或把 allow 当成形容词。
- 错 E 一致错（is allowed）：默认 be 用 is，没看 Students 是复数。
- 错 F 换词/加冠词（are permitted / a dictionary）：把改写题当翻译题或改错题，顺手“优化”原句。

**⑧ 可迁移规则**

**ST-01（allow 类被动）**：if 主动句 = S + allow/ask/tell/expect/want + O + to do，且指令“变被动” → then O 提前作主语 + be（与原句时态、新主语人称数一致）+ V-ed + to do（+ by S 可省）。

操作步骤：

1. 定谓语和宾语：allow + students。
2. 宾语提前：students → 主语（保持复数）。
3. 定 be：原句一般现在时、新主语复数 → are。
4. 定分词：allow → allowed。
5. 保留补足语：to use dictionary 原样不动。
6. 省 by us：泛指施事，且无空位。
7. 校验：主语 + are + allowed + to do；时态、数、意义、空外成分。

例外/对照：make/let/have/see/hear + O + do → 被动要补 to（He was made to work）；allow doing（无宾语）→ Doing is not allowed. 若原句是“allow + 动名词”，不要套 ST-01。

**⑨ 模型位置**

04 → 句型转换 → 语态 → 被动语态（VOICE-01）；下挂“allow 类 to 保留 / make 类 to 复原”对照对。

- 与 02_连词成句 R8（be + V-ed）同机制，但入口不同：R8 是“给块排序”，ST-01 是“给句改态”。
- 与 05_翻译填空的“被”字句共用 VOICE-01，但翻译填空从汉语出发，可能选 permit/allow；本题不许换词。
- 冲突：be + V-ed（被动）vs be + adj（系表）。判别：V-ed 后能否补 by 短语、原句是否有及物动词宾语；优先级：先定时态与主语数，再定 be，再定分词。
- 冲突：被动 vs 时态。优先级：时态保持优先；不能为了“看起来像被动”改成 were allowed。

**⑩ 自检清单**

- 主语是不是原句宾语？数对了吗？
- be 的时态与原句一致吗？
- 实义动词是过去分词吗？
- to 还在吗？有没有把 to 丢掉或改成 to doing？
- 有没有多写 by us、加冠词、改 dictionary？
- 两个空是否各一词、拼写正确？

42. She has many good qualities besides being very beautiful.（变否定）

She ______ ______ many good qualities besides being very beautiful.

> **答案：doesn't have**（doesn't 按一个词计；does 与 She 一致，have 为原形）

**① 题面事实**

- 原句：She has many good qualities besides being very beautiful.
- 指令：变否定。
- 空位：She ______ ______ many good qualities besides being very beautiful. 两个空，位于主语 She 之后、宾语 many good qualities 之前；空外保留 besides being very beautiful。
- 句法事实：She + has（实义动词 have，第三人称单数一般现在时，表“拥有”）+ 宾语 many good qualities + 介词短语 besides being very beautiful（补充说明）。
- 提示形式：无括号词、无首字母；中文指令“变否定”是唯一提示。
- 诱导信号：① has 既可作助动词（has finished）又可作实义动词（has qualities），题面正好用后者；② 两空刚好容 doesn't + have，也刚好容 has + not（旧式变体），形成口径陷阱；③ besides being very beautiful 是第二个谓语候选，容易把否定加到 being/beautiful 上；④ many 在否定句中容易被他改成 much/any；⑤ 汉语“她没有很多优点”的语序与英语否定相近，容易直译成 She not has...
- 原卷核对：PDF 第 6 页；原句 has 无缩写，宾语 many good qualities 完整。

**② 候选空间**

空位是谓语否定段：操作词 + not（+ 实义动词）。可能类别有：① do/does/did + not + V（do-support，唯一合格类）；② have/has + not（助动词路径合格；实义 have 属旧式变体）；③ 情态 + not + V；④ 否定限定词（few/no）；⑤ 否定词位置错（not 在实义动词前/后）；⑥ 否定错对象（besides being...）。

| 候选 | 结构归属 | 错型标签 |
|---|---|---|
| doesn't have | does + not + have（缩合） | ✅ 目标 |
| does not have | does + not + have（展开） | 空数不合（3 词） |
| didn't have | did + not + have | 时态错 |
| don't have | do + not + have | 一致错 |
| hasn't have | has + not + have | 形态错/双助动词 |
| has not | has + not（直接否定） | 旧式变体/口径风险 |
| hasn't got | has + not + got | 换词/增词（英式口语） |
| not have | not + have | 漏助动词 |
| does have not | does + have + not | 语序错 |
| doesn't has | does + not + has | 形态错/双重标记 |
| has few | few 否定限定词 | 换词/意义偏移 |

本题至少给出 10 种错写，覆盖时态错、语序错、漏助动词三类必测错型。

**③ 逐项验算**

- ✅ **doesn't have**：She doesn't have many good qualities besides being very beautiful. does 与 She 一致，not 否定谓语，have 为原形；时态仍为一般现在时；many 保留；成立。两空各一词（doesn't 按一个词计）。
- ❌ **does not have**（B 空数）：She does not have many good qualities... 语法完全成立，但需要三个词（does / not / have），本题只有两个空；若把 does not 挤进第一空，违反“每空一词”的默认。不得分。注：若考场允许一空多词，这是合法展开式；本题按两空取缩合。
- ❌ **didn't have**（B 时态）：She didn't have many good qualities... 语法成立，但原句 has 是一般现在时，改写后成过去；无过去时间参照，违反时态保持。不得分。
- ❌ **don't have**（A 一致）：She don't have many good qualities... 主语第三人称单数，操作词必须 does；违反主谓一致（非标准方言除外）。不成立。
- ❌ **hasn't have**（A 形态）：She hasn't have many good qualities... has 已是助动词/否定词，后面又接 have 原形，两个限定核心冲突；且实义 have 的否定不用 has + not + have。不成立。
- ❌ **has not**（B 口径/焦点）：She has not many good qualities... 这是旧式书面/英式变体，语法可通；但现代标准英语（尤其考试口径）对实义 have 的否定用 do-support；且 not 直接修饰 many，否定焦点落在数量上，不是否定“拥有”这一谓语。按本题“变否定谓语”的操作定义，不取。标为口径风险：若官方答案给 has not，需按卷面口径复核。
- ❌ **not have**（A 漏助动词）：She not have many good qualities... 缺少操作词 does；标准英语中 not 不能直接放在实义动词前（除情态/助动词/be 外）。不成立。
- ❌ **does have not**（A 语序）：She does have not many good qualities... not 必须紧跟操作词 does，不能放在实义动词 have 后；违反否定词位置。不成立。
- ❌ **doesn't has**（A 形态）：She doesn't has many good qualities... does 已承载第三人称单数，实义动词必须还原为 have；双重标记。不成立。
- ❌ **hasn't got**（B 换词/增词）：She hasn't got many good qualities... 英式口语里语法可通，也正好占两空；但原句没有 got，添加 got 属于增词，违反“空外冻结”；本题按现代标准书面语取 do-support。不得分。
- ❌ **has few**（B 换词/意义）：She has few good qualities... 语法成立，但把 many 换成 few，且否定限定词否定的是数量，不是谓语；违反“空外词汇不动 / 只改指令要求的范畴”。不得分。
- 结论：在两空、现代标准英语、否定谓语三个条件下，只有 **doesn't have** 同时满足。

**④ 干扰项设计**

- has 的双重身份是主陷阱：学生背过“have → haven't”，看到 has 就写 hasn't；但本题 has 是实义动词，否定要 do-support。
- 两空设计：doesn't + have 正好；has + not 也正好；hasn't + got 也正好（英式口语），三者构成“词形都对、口径不同”的陷阱；does not + have 三词则被空数排除。
- besides being very beautiful 是“第二个谓语”诱饵：学生可能写 besides not being beautiful（否定伴随状态）或 besides being not beautiful（否定形容词），都改变了否定对象。
- many 是“否定词形”诱饵：学生可能改 much（不可数）或 any（否定句常用），但空外不动。
- 汉语直译“她没有很多优点”没有 do-support，容易写 She not has / She no has。

**⑤ 命题意图**

- 考“实义动词 have 的否定需要 do-support”，核心是识别 has 的谓语身份（实义 vs 助动词）。
- 区分两类人：背“have → haven't”的人（hasn't）；先判谓语类型的人（doesn't have）。
- 为什么用这个句子：has 的两种身份在同一词形上重合，是最干净的对立项；besides being... 把否定范围问题一起考出来；many 考“否定时不要改限定词”。

**⑥ 判别边界**

- 实义 have vs 助动词 have：She has many qualities.（实义，否定 doesn't have）vs She has finished.（助动词，否定 hasn't finished）。判别：has 后若是名词/名词短语作宾语 → 实义；若是过去分词 → 助动词。
- have got：She hasn't got many good qualities. 英式口语替代，语法可通且正好两空；但原句无 got，添加 got 属于增词，违反空外冻结；本题按现代标准书面语取 do-support。
- has not many：旧式/书面变体；现代考试取 do-support；若出现，按口径风险处理。
- 否定范围：否定谓语（doesn't have）vs 否定伴随状态（besides not being beautiful）vs 否定形容词（besides being not beautiful）——本题只允许第一种。
- many vs much/any：many 修饰可数复数 qualities；否定句中可换 any，但本题空外冻结；much 修饰不可数，直接错。
- 与连词成句：连词成句给块，可能给 doesn't / have / many...；本题给完整句，只挖否定段，考“操作词插入”，不是排序。
- 与翻译填空：翻译“她没有很多优点”可写 She has few good qualities / She doesn't have many...；句型转换只能走“否定谓语”这一条，且保留 many。
- 与改错：改错若原句是 She don't have...，要改成 doesn't；本题原句正确，是“按指令生成否定”，方向相反。

**⑦ 错误类型**

- 错 A 助动词误判（hasn't / hasn't have）：把实义 has 当助动词，或把两个助动词叠用；错因：只记词形，不判谓语身份。
- 错 B 漏 do-support（She not have）：汉语“不”直接放在动词前，负迁移；错因：不知道实义动词否定需要操作词。
- 错 C 操作词不一致（don't have）：只记 don't，不看第三人称单数；错因：do-support 只记一半。
- 错 D 双重标记（doesn't has）：does 已表第三人称，实义动词未还原；错因：形态操作不完整。
- 错 E 否定词位置错（does have not）：把 not 贴在实义动词后；错因：不知道 not 紧跟操作词。
- 错 F 否定对象错（besides not being beautiful）：把否定加到伴随状语；错因：没做否定范围检验。
- 错 G 改限定词（much/any/few）：把否定句的“任何/很少”当成必须改词；错因：把语法否定和词汇替换混在一起。

**⑧ 可迁移规则**

**ST-02（实义动词否定）**：if 指令“变否定”且谓语是实义动词（含表“拥有”的 have），时态为一般现在时/一般过去时 → then do/does/did + not + V 原形；第三人称单数现在时用 does，V 还原；其余成分不动。

操作步骤：

1. 判谓语身份：实义动词还是助动词/情态/be。
2. 定时态与人称：现在时第三人称单数 → does；过去时 → did；其余 → do。
3. 放 not：紧跟操作词。
4. 还原实义动词：has → have；likes → like；went → go。
5. 保留其余：宾语、状语、限定词 many 不动。
6. 校验：否定范围是否只落在谓语；空数是否够（缩合 vs 展开）。

例外：助动词 have（has finished）→ has not finished；be 动词 → is not；情态 → cannot；have got → hasn't got（需有 got）。对照：has not many 旧式变体不取；few/no 是否定限定词，不是谓语否定。

**⑨ 模型位置**

04 → 句型转换 → 否定 → 实义动词否定（NEG-01，建议 ID）；下挂“do-support”与“have 双重身份”对照。

- 与 01 的时态节点（TENSE-01）联合：先定时态，再定操作词；与 AGR-01 联合：does 与主语一致。
- 与 02_连词成句 R12（骨架与情态）相邻：都要求先定谓语核心；但连词成句是“拼骨架”，本题是“换否定形态”。
- 冲突：do-support vs have 自身否定。优先级：先判 have 是实义还是助动词；实义 → do-support，助动词 → not。
- 冲突：缩合 vs 展开。优先级：空数优先；两空取 doesn't，三空才写 does not。

**⑩ 自检清单**

- has 是实义动词还是助动词？后面接的是名词还是过去分词？
- 操作词与主语一致吗（She → does）？
- 实义动词还原成 have 了吗？
- not 是紧跟操作词吗？
- many 有没有被改成 much/any/few？
- 否定的是谓语，还是 besides being...？
- 两空够不够？doesn't 按一个词计。

43. There are a lot of high buildings near the newly-built park.（变一般疑问句）

______ ______ a lot of high buildings near the newly-built park?

> **答案：Are there**（句首大写；be 用 are 与复数 NP 一致）

**① 题面事实**

- 原句：There are a lot of high buildings near the newly-built park.
- 指令：变一般疑问句。
- 空位：______ ______ a lot of high buildings near the newly-built park? 两个空在句首；空后保留 a lot of high buildings near the newly-built park；句末已有问号。
- 句法事实：There be 存在句；be = are（复数）；notional subject = a lot of high buildings（复数）；地点状语 near the newly-built park。
- 提示形式：无括号词；问号已在空外。
- 诱导信号：① There are 本身像疑问框架，容易只加问号不改语序；② a lot of 紧挨 are，学生可能按“a lot”单数写 Is there；③ there 与 they 形近，容易代词化；④ 两个空容易写成 Are there / Is there / There are / Do there；⑤ 句末问号已给，容易忘记首字母大写。
- 原卷核对：PDF 第 6 页；原句 are 为复数，buildings 为复数。

**② 候选空间**

空位是句首疑问操作段：be + there。可能类别有：① Be + there + NP（唯一合格类）；② Is there（数错）；③ There are（不倒装）；④ Do there（错操作词）；⑤ Are they（代词化）；⑥ Have there（错动词）；⑦ Are there any（改限定词）；⑧ Were there（时态错）；⑨ There a lot...（漏 be）。

| 候选 | 结构归属 | 错型标签 |
|---|---|---|
| Are there | be(are) + there | ✅ 目标 |
| Is there | be(is) + there | 一致错 |
| There are | there + be（陈述序） | 语序错/未倒装 |
| Were there | be(were) + there | 时态错 |
| Do there | do + there | 操作词错 |
| Are they | be + they | 代词化/结构错 |
| Have there | have + there | 动词错 |
| Are there any | be + there + any | 换限定词 |
| There a lot of... | there + NP（缺 be） | 漏助动词 |

本题至少给出 8 种错写，覆盖时态错、语序错、漏助动词三类必测错型。

**③ 逐项验算**

- ✅ **Are there**：Are there a lot of high buildings near the newly-built park? be 提前，there 紧随，NP 与地点状语不动；are 与复数 NP 一致；一般疑问句成立。
- ❌ **Is there**（A 一致）：Is there a lot of high buildings near the newly-built park? be 与 notional subject 不一致；a lot of + 复数可数名词 → are。若 a lot of + 不可数（water）才用 is。不成立。
- ❌ **There are**（A 语序/句式）：There are a lot of high buildings...? 仍是陈述语序；问号只改变语调，不是一般疑问句的语法形式；两个空填 There / are 后句子原样，未执行倒装。不成立（作回声问句另算，不是本题目标）。
- ❌ **Were there**（B 时态）：Were there a lot of high buildings...? 语法成立，但原句 are 是现在时，改写后成过去；无过去参照，违反时态保持。不得分。
- ❌ **Do there**（A 操作词）：Do there a lot of high buildings...? there-be 的疑问用 be，不用 do-support；do there 后还缺动词。不成立。
- ❌ **Are they**（A 结构/指代）：Are they a lot of high buildings...? they 无先行词，且把 there-be 改成主系表；意义/结构都变。不成立。
- ❌ **Have there**（A 动词）：Have there a lot of high buildings...? there-be 不用 have；若表“有”应用 there be，不是 have there。不成立。
- ❌ **Are there any**（B 换词）：Are there any high buildings...? 语法成立，但把 a lot of 换成 any，改变数量限定；空外冻结。不得分。
- ❌ **There a lot of...**（A 漏助动词）：There a lot of high buildings near the newly-built park? there 后缺 be，句子没有限定谓语。不成立。
- 结论：只有 **Are there** 同时满足 there-be 疑问语序、复数一致、时态保持、空外不动。

**④ 干扰项设计**

- There are 的语序与疑问语序只差一个倒装，学生容易“看到问号就以为变了”；两个空正好容 There / are，制造“原样填入”的陷阱。
- a lot of 紧挨 are，按邻近原则可能写 Is there；出题人用复数 buildings 考 notional agreement。
- there / they 形近，且学生学过“用 they 代指前文”，容易写 Are they。
- 句末问号已给，学生可能忘记句首 Are 大写；这是评分点。
- any 是疑问句的“自然搭配”，容易顺手改 a lot of → any，违反空外冻结。

**⑤ 命题意图**

- 考 there-be 存在句的一般疑问句构成（be + there），以及 a lot of + 复数名词的主谓一致。
- 区分三类人：只加问号的人（There are...?）；按“a lot”单数选 is 的人（Is there）；能看 notional subject 并倒装的人（Are there）。
- 为什么用这个句子：there-be 是最典型的存在句；a lot of 是“形式单数、意义复数”的经典一致陷阱；地点状语长，考“只动 be 和 there，其余不动”。

**⑥ 判别边界**

- there-be 一般疑问 vs 特殊疑问：Are there...?（一般）vs How many buildings are there...?（特殊）；本题只要求一般疑问，不要加 How many/Where。
- there-be vs have：There are...（存在）vs They have...（拥有）；疑问分别是 Are there...? / Do they have...? 不能混。
- a lot of + 复数 vs + 不可数：Are there a lot of buildings? / Is there a lot of water? 一致看名词，不看 lot。
- 一般疑问 vs 回声问句：There are...? 可作回声问句（升调），但不是标准一般疑问句；本题要标准形式。
- 一般疑问 vs 反意疑问：Are there...? vs There are..., aren't there? 后者是 tag，不是本题。
- 与连词成句：连词成句可能给 Are / there / a lot of... 词块，考排序；本题给陈述句，考倒装操作。
- 与翻译填空：翻译“公园附近有很多高楼吗？”可直接写 Are there...?，但翻译填空可能选 Is there / Are there，取决于名词数；本题原句已定复数，答案唯一。
- 与改错：改错若原句 Is there a lot of buildings，要改 Is→Are；本题原句正确，方向相反。

**⑦ 错误类型**

- 错 A 未倒装（There are...?）：把疑问句等同于加问号；错因：不知道一般疑问句要 be 提前。
- 错 B 一致错（Is there）：按 a lot 的单数形式选 is；错因：邻近原则压过 notional agreement。
- 错 C 操作词错（Do there）：把 there-be 当实义动词，套 do-support；错因：没识别 there-be 的 be 是操作词。
- 错 D 代词化（Are they）：there 与 they 混；错因：把存在句的 there 当成代词。
- 错 E 时态漂移（Were there）：换 be 形式时忽略原句时态；错因：只盯句式，不盯时态。
- 错 F 改限定词（any）：疑问句顺手改 any；错因：把语法转换和词汇替换混在一起。
- 错 G 大小写/拼写（are there）：句首未大写；错因：只关注语法，忽略书面规范。

**⑧ 可迁移规则**

**ST-03（there-be 一般疑问）**：if 陈述句 = There + be + NP + 地点/时间，指令“变一般疑问句” → then Be + there + NP + ...?；be 与 NP 的数一致；其余不动。

操作步骤：

1. 找 there-be 的 be。
2. 定 NP 的数：a lot of + 复数可数 → 复数；a lot of + 不可数 → 单数。
3. be 提前到句首，there 紧随。
4. 其余（NP、地点状语）原样。
5. 句末问号；句首大写。
6. 校验：be 与 NP 一致；时态不变；没有 do-support。

例外：若原句是 There + 情态 + be（There will be...），疑问是 Will there be...?；若 There + seem/appear，疑问是 Do there seem...?（seem 是实义动词，需 do-support）。这是边界，别把 there-be 规则泛化到 there seem。

**⑨ 模型位置**

04 → 句型转换 → 疑问句 → 一般疑问（QUES-01，建议 ID）；下挂 there-be 子类。

- 与 AGR-05（there be 就近/主谓一致）联合；与 02_连词成句 R4（疑问语序）同机制，但入口不同。
- 与 QUES-02（特殊疑问）对照：一般疑问只倒装，不加疑问词；特殊疑问加疑问词并倒装。
- 冲突：there-be 用 be vs 实义动词用 do。优先级：先判谓语是不是 be；是 be → be 提前；不是 → do-support。
- 冲突：形式单数 a lot vs 意义复数 buildings。优先级：看名词的数，不看量词 lot。
- 冲突：一般疑问 vs 回声问句。优先级：标准形式优先；回声问句不是答案。

**⑩ 自检清单**

- be 提前了吗？there 紧随其后吗？
- be 与 a lot of 后的名词数一致吗？
- 有没有误加 do/does？
- 时态还是现在时吗？
- a lot of 有没有被改成 any？
- 句首 Are 大写了吗？句末问号是一个吗？

44. They will go to the library next Sunday.（对划线部分提问）

______ ______ they go to the library?

> **答案：When will**（原卷下划线在 next Sunday 下；When 替换时间状语，will 提前）

**① 题面事实**

- 原句：They will go to the library next Sunday.
- 指令：对划线部分提问。
- 划线：原卷 PDF 第 6 页下划线在 next Sunday 下；转写稿未保留划线。next Sunday 是时间状语，不是主语、宾语或地点。
- 空位：______ ______ they go to the library? 两个空在句首；空后保留 they go to the library；句末问号。
- 句法事实：They + will（情态助动词）+ go（原形）+ to the library（地点状语）+ next Sunday（时间状语）。
- 提示形式：无括号词；划线是唯一操作对象。
- 诱导信号：① 划线在句末，容易被忽略，转而提问 They（Who）或 the library（Where）；② will 已是操作词，学生可能套“疑问句用 do”写 When do；③ 空后 they go 是原形，既容 will 也容 do，形态上不报警；④ 两空容易写 When will / When do / What will / Where will；⑤ next Sunday 可能被保留，造出 When...next Sunday 的双重时间。

**② 候选空间**

空位是“疑问词 + 操作词”。可能类别有：① When + will（唯一合格类）；② When + do/did（时态/操作词错）；③ When + S + will（不倒装）；④ What/Where/Who/How + will（疑问词错）；⑤ 保留 next Sunday（未删除划线）；⑥ When + will + V-ing（形态错）；⑦ Will they...?（没加疑问词）。

| 候选 | 结构归属 | 错型标签 |
|---|---|---|
| When will | wh + will | ✅ 目标 |
| When do | wh + do | 时态/操作词错 |
| When did | wh + did | 时态错 |
| When they will | wh + S + will | 语序错（未倒装） |
| When go they | wh + V + S | 漏操作词 |
| What will | wh + will | 疑问词错 |
| Where will | wh + will | 疑问词错 |
| When will they go next Sunday | 保留划线 | 未删除/空位不合 |
| When will they going | will + V-ing | 形态错 |

**③ 逐项验算**

- ✅ **When will**：When will they go to the library? When 替换 next Sunday，will 提前，they 紧随，go 原形；时态仍将来；地点状语保留；成立。
- ❌ **When do**（B 时态/操作词）：When do they go to the library? 语法成立，但原句 will 是将来，do 把时态改成一般现在（习惯/经常）；且 will 被删，违反时态保持。不得分。
- ❌ **When did**（B 时态）：When did they go to the library? 过去时；原句将来；违反时态保持。不得分。
- ❌ **When they will**（A 语序）：When they will go to the library? 这是宾语从句语序（疑问词 + 主语 + 谓语），直接疑问句必须 will + they；不成立（若作回声问句另算）。
- ❌ **When go they**（A 漏操作词）：When go they to the library? 现代标准英语中实义动词 go 不能直接提到主语前；缺少 will/do 操作词。不成立。
- ❌ **What will**（A 疑问词）：What will they go to the library? 语义/句法都不成立；What 不能替代时间状语；若问“做什么”应改整个谓语（What will they do?），超出本题划线范围。
- ❌ **Where will**（B 疑问词/目标错）：Where will they go to the library? 语法可通但语义冗余/错误：Where 问地点，而 to the library 已保留；划线是时间，不是地点。不得分。
- ❌ **保留 next Sunday**（B 未删除/空位）：When will they go to the library next Sunday? 语法可通，但 next Sunday 是划线部分，提问后必须删除；且框架没有第三个空位；双重时间参照，语义重复。不得分。
- ❌ **When will they going**（A 形态）：When will they going to the library? will 后要求动词原形，going 是现在分词。不成立。
- 结论：只有 **When will** 同时满足“疑问词对应时间、操作词用 will、倒装、删除划线、时态保持”。

**④ 干扰项设计**

- 划线在句末且转写稿丢失下划线，是最大的信息陷阱；学生可能按“对主语提问”写 Who will，或按“对地点提问”写 Where will。
- will 是操作词，但学生有“疑问句 = do/does/did”的强规则，容易写 When do；空后 go 是原形，do 和 will 都能接，形态上不报警。
- 两空正好容 When will / When do / What will / Where will，制造“词都能填”的错觉。
- next Sunday 在句末，学生可能把它留在原位，造出 When...next Sunday 的双重时间；框架的两个空也“看起来”不影响保留它。
- 问号已给，学生可能只加疑问词不倒装（When they will...）。

**⑤ 命题意图**

- 考“对划线状语提问”的完整操作：确定划线成分 → 选疑问词 → 删除划线 → 操作词倒装 → 保持时态。
- 区分三类人：见疑问句就补 do 的人（When do）；只加疑问词不倒装的人（When they will）；能识别 will 已是操作词并保留将来时的人（When will）。
- 为什么用这个句子：will 是现成操作词，能干净地隔离“不要补 do”的规则；next Sunday 是明确时间状语，疑问词唯一；句末状语位置考“删除划线”而不是“保留”。

**⑥ 判别边界**

- 时间状语 vs 地点/方式/原因：next Sunday → When；to the library → Where；by bus → How；because... → Why。划线不同，疑问词不同。
- 特殊疑问 vs 一般疑问：When will...?（特殊，有疑问词）vs Will they...?（一般，无疑问词）；本题必须加 When。
- 直接疑问 vs 宾语从句：When will they go...?（倒装）vs I don't know when they will go...（陈述序）；本题是直接疑问，必须倒装。
- 操作词已存在 vs 需 do-support：will/can/be/have（助动词）→ 直接提前；实义动词 → 补 do/does/did。本题 will 已存在，不补 do。
- When vs What time：What time 也可问时间，但它是两个词，会占满两个空并挤掉 will；框架只容 When + will，故不取。
- When will vs When shall：shall 是英式变体，语法可通，但改了原句的情态动词 will；原词冻结，不取。
- 划线删除 vs 保留：提问后划线部分必须删除；保留 next Sunday 会双重时间，且框架无位置。
- 与连词成句：连词成句给 When / will / they / go 等块，考排序；本题给陈述句 + 划线，考“疑问词选择 + 删除 + 倒装”。
- 与翻译填空：翻译“他们下周日什么时候去图书馆？”可能写成 When will they go...? 也可能写成 What time...；本题框架限定 When + will，排除 What time。
- 与改错：改错若原句 When they will go? 要改成 When will they go?；本题原句正确，方向相反。

**⑦ 错误类型**

- 错 A 操作词误补（When do）：把“疑问句用 do”泛化到已有 will 的句子；错因：不检查原句是否已有操作词。
- 错 B 时态漂移（When did / When do）：换操作词时把将来改成过去/现在；错因：只盯疑问句式，不盯时态。
- 错 C 未倒装（When they will）：把直接疑问句写成宾语从句语序；错因：混淆直接疑问与间接疑问。
- 错 D 漏操作词（When go they）：实义动词直接提前；错因：不知道倒装需要操作词。
- 错 E 疑问词错（What/Where/Who）：没看划线成分，或按“句末名词”猜；错因：划线识别失败。
- 错 F 未删除划线（...next Sunday）：只加疑问词，不删原状语；错因：没执行“替换”操作。
- 错 G 形态错（will going）：will 后未用原形；错因：情态动词后的形态规则不牢。

**⑧ 可迁移规则**

**ST-04（划线状语提问）**：if 指令“对划线部分提问”且划线是时间/地点/方式/原因状语 → then 疑问词（When/Where/How/Why）+ 操作词 + 主语 + 谓语原形 + 其余?；删除划线；操作词取原句（will/can/be/助动词），无则补 do/does/did。

操作步骤：

1. 定划线成分和句法角色。
2. 选疑问词：时间 When，地点 Where，方式 How，原因 Why。
3. 删除划线成分。
4. 定操作词：原句有 will/can/be/have（助动词）→ 直接提前；只有实义动词 → 补 do/does/did。
5. 倒装：操作词 + 主语 + 实义动词原形 + 其余。
6. 校验：时态不变、疑问词对应划线、划线已删、语序倒装、问号一个。

例外：对主语提问（Who/What）不倒装，直接把主语换成疑问词（Who will go?）；对宾语提问用 What/Who，可能保留或删除介词；本题是状语，不适用主语例外。

**⑨ 模型位置**

04 → 句型转换 → 疑问句 → 特殊疑问（QUES-02，建议 ID）；下挂“状语提问”子类。

- 与 QUES-01（一般疑问）对照：特殊疑问 = 疑问词 + 一般疑问语序；与 02_连词成句 R4（疑问语序）同机制。
- 与 01 的 TENSE-01 联合：先定时态，再定操作词；与 INV-01 相邻：特殊疑问句是 wh + 部分倒装。
- 冲突：已有操作词 vs 补 do。优先级：已有 will/can/be → 直接提前；无 → 补 do。
- 冲突：When vs What time。优先级：框架空数 + 原句操作词；两空只能 When + will。
- 冲突：直接疑问 vs 宾语从句。优先级：问号 + 主句 → 直接疑问倒装；从句 → 陈述序。
- 冲突：划线删除 vs 保留。优先级：删除优先；保留会造成双重时间/地点。

**⑩ 自检清单**

- 划线的是哪个成分？时间、地点、方式还是原因？
- 疑问词选对了吗？
- 原句有操作词吗？是 will 还是需要 do？
- 倒装了吗？还是写成了从句语序？
- 划线部分删掉了吗？next Sunday 还在不在？
- 时态还是将来吗？go 是原形吗？
- 两空是 When + will 吗？

45. He not only likes reading books, but also listening to soft music.（变倒装句）

Not only ______ ______ like reading books, but also listening to soft music.

> **答案：does he**（Not only 前置触发部分倒装；does 与 he 一致，likes 还原为 like）

**① 题面事实**

- 原句：He not only likes reading books, but also listening to soft music.
- 指令：变倒装句。
- 空位：Not only ______ ______ like reading books, but also listening to soft music. 两个空在 Not only 后、like 前；空后保留 like reading books, but also listening to soft music。
- 句法事实：Not only ... but also ... 连接两个并列成分；第一分句 He likes reading books；第二分句 (he likes) listening to soft music，省略主语和谓语；likes 是实义动词第三人称单数一般现在时；原句无助动词。
- 提示形式：句首 Not only 已给；中文指令“变倒装句”是操作提示。
- 诱导信号：① Not only 在句首，但学生可能不知道它触发倒装；② 原句无助动词，学生可能直接写 he does / he likes，或忘记补 does；③ likes 的 -s 容易保留成 does he likes；④ 第二分句 but also listening 是省略结构，容易误以为要一起倒装（but also does he listen）；⑤ 两个空正好容 does he / did he / he does / is he。
- 原卷核对：PDF 第 6 页；原句 likes 为第三人称单数，第二分句 listening 前省略了 likes。

**② 候选空间**

空位是 Not only 后的“操作词 + 主语”。可能类别有：① 操作词 + 主语（部分倒装，唯一合格类）；② 主语 + 操作词（不倒装）；③ 主语 + 实义动词（完全不倒装）；④ 实义动词 + 主语（无操作词直接倒装）；⑤ 错操作词（is/has）；⑥ 双重标记（does he likes）；⑦ 第二分句也倒装；⑧ 时态错（did he）。

| 候选 | 结构归属 | 错型标签 |
|---|---|---|
| does he | does + he | ✅ 目标 |
| did he | did + he | 时态错 |
| he does | he + does | 语序错（未倒装） |
| he likes | he + likes | 未倒装/漏操作词 |
| likes he | likes + he | 漏操作词/实义动词倒装 |
| is he | is + he | 操作词错 |
| has he | has + he | 操作词错 |
| does he likes | does + he + likes | 形态错/双重标记 |
| does he like + but also does he listen | 第二分句倒装 | 范围错/空位不合 |

本题至少给出 8 种错写，覆盖时态错、语序错、漏助动词三类必测错型。

**③ 逐项验算**

- ✅ **does he**：Not only does he like reading books, but also listening to soft music. Not only 前置触发部分倒装；does 与 he 一致，like 还原原形；第二分句按原框架保留；成立。
- ❌ **did he**（B 时态）：Not only did he like reading books... 语法成立，但原句 likes 是一般现在时，did 改成过去；违反时态保持。不得分。
- ❌ **he does**（A 语序）：Not only he does like reading books... 在本题 Not only...but also 的倒装框架中，Not only 后必须操作词 + 主语，不能主语 + 操作词；he does 是不倒装的强调式，未执行倒装。不成立。
- ❌ **he likes**（A 语序/漏操作词）：Not only he likes reading books... 在本题框架中既没倒装，也没补 does；Not only 前置的倒装要求未满足。不成立。
- ❌ **likes he**（A 漏操作词）：Not only likes he reading books... 实义动词 likes 直接提到主语前；现代标准英语不允许实义动词直接倒装，必须借助 do/does/did。不成立。
- ❌ **is he**（A 操作词）：Not only is he like reading books... is 与 like 冲突（be + 动词原形）；且 likes 是实义动词，不是进行/被动。不成立。
- ❌ **has he**（A 操作词）：Not only has he like reading books... has 与 like 冲突；原句不是完成体。不成立。
- ❌ **does he likes**（A 形态）：Not only does he likes reading books... does 已表第三人称单数，实义动词必须还原 like；双重标记。不成立。
- ❌ **第二分句也倒装**（B 范围/空位）：Not only does he like reading books, but also does he listen to soft music. 语法上可通（并列倒装），但原框架已给 but also listening，第二分句没有空位；改写超出指令范围，且改变原句省略结构。不得分。
- 结论：只有 **does he** 同时满足“Not only 触发部分倒装 + 操作词与主语一致 + 实义动词还原 + 第二分句不动 + 时态保持”。

**④ 干扰项设计**

- Not only 在句首是显性信号，但学生可能只把它当“不仅”的连词，不知道它触发倒装；于是写 he likes / he does。
- 原句没有助动词，学生必须补 does；这是“倒装 + do-support”的双重操作，容易只做一半：likes he（只倒装，不补 do）或 he does（只补 do，不倒装）。
- likes 的 -s 是形态陷阱：does 已表第三人称，likes 必须还原；学生容易写 does he likes。
- 第二分句 but also listening 是省略结构，学生容易“平行处理”成 but also does he listen；框架没有这个空。
- 两个空正好容 did he / is he / has he，制造“操作词随便选”的错觉；时态和谓语类型是判别依据。

**⑤ 命题意图**

- 考“Not only 置于句首的部分倒装”：操作词 + 主语，实义动词留原位；无助动词时补 do-support。
- 区分四类人：完全不动的人（he likes）；只补 do 不倒装的人（he does）；只倒装不补 do 的人（likes he）；能同时完成“补 does + 倒装 + 还原 like”的人（does he）。
- 为什么用这个句子：Not only 是显性触发词；原句无助动词，强制 do-support；第二分句的省略结构考“倒装范围”，防止学生把整句都倒装。

**⑥ 判别边界**

- Not only vs only/never/hardly/little：这些否定/限制成分置于句首都触发部分倒装；但 only + 状语倒装（Only then did I...）与 Not only...but also 的并列结构不同，别混。
- 部分倒装 vs 完全倒装：部分倒装 = 操作词 + 主语 + 实义动词（Not only does he like...）；完全倒装 = 状语/表语 + 动词 + 主语（Here comes the bus）。本题是部分倒装。
- 第一分句 vs 第二分句：Not only 只触发第一分句倒装；第二分句 but also 后按原框架保留（but also listening）；若要倒装第二分句，需另加操作词，框架不允许。
- 操作词已存在 vs 需 do-support：原句有 will/can/be/助动词 → 直接提前（Not only will he...）；只有实义动词 → 补 does（本题）。本题原句无助动词，必须补。
- 倒装 vs 强调 do：He does like... 是强调，不是倒装；Not only he does like... 仍不倒装；两者不同。
- 与连词成句：连词成句可能给 Not only / does / he / like 块，考排序；本题给完整句，考“补操作词 + 倒装 + 还原”。
- 与翻译填空：翻译“他不仅喜欢读书，而且喜欢听轻音乐”可写 Not only does he like... 也可写 He not only likes...；本题指令明确“变倒装”，必须走倒装。
- 与改错：改错若原句 Not only he likes...，要改成 Not only does he like...；本题原句正确，方向相反。

**⑦ 错误类型**

- 错 A 未倒装（he likes / he does）：不知道 Not only 前置触发倒装；错因：只把 Not only 当连词，不看语序。
- 错 B 漏 do-support（likes he）：知道要倒装，但把实义动词直接提前；错因：不知道倒装必须借助操作词。
- 错 C 双重标记（does he likes）：does 已表第三人称，likes 未还原；错因：形态操作不完整。
- 错 D 操作词错（is he / has he）：把 be/完成体助动词套到实义动词上；错因：不判谓语类型。
- 错 E 时态漂移（did he）：补操作词时改成过去；错因：只盯倒装，不盯时态。
- 错 F 范围错（第二分句也倒装）：把 Not only 的倒装扩展到 but also 分句；错因：没看框架已给的第二分句，过度操作。
- 错 G 语序错（he does）：补了 does 但没倒装；错因：只完成 do-support，没完成移位。

**⑧ 可迁移规则**

**ST-05（Not only 前置部分倒装）**：if 句首 = Not only + 第一分句，指令“变倒装句” → then Not only + 操作词 + 主语 + 实义动词原形 + 其余，but also 分句按原框架保留；操作词原句有则提前，无则补 do/does/did。

操作步骤：

1. 确认 Not only 在句首，且连接两个并列成分。
2. 找第一分句的主语和谓语：He / likes。
3. 判操作词：原句无助动词 → 补 does（与 He 一致、现在时）。
4. 倒装：does + he。
5. 实义动词还原：likes → like。
6. 第二分句不动：but also listening to soft music。
7. 校验：Not only + does + he + like；时态、数、第二分句、空数。

例外：原句有助动词/情态 → 直接提前（Not only can he... / Not only has he...）；be 动词 → Not only is he...；第二分句若要倒装，需另加操作词，本题框架不允许。

**⑨ 模型位置**

04 → 句型转换 → 倒装 → 部分倒装（INV-01，复用 01）；下挂“Not only...but also”子类。

- 与 INV-02（Only + 状语倒装）对照：两者都触发部分倒装，但触发词和范围不同；与 INV-03（完全倒装）对照：部分倒装只移操作词，完全倒装移整个谓语。
- 与 02_连词成句 R4（疑问语序）同机制：操作词 + 主语；但本题是陈述句倒装，不是疑问。
- 与 AUX-01（do-support）联合：无助动词 → 补 does；与 AGR-01 联合：does 与 he 一致。
- 冲突：部分倒装 vs 完全倒装。优先级：看谓语类型；实义动词 → 部分倒装（补 do）；be → 完全/部分按句式。
- 冲突：第一分句 vs 第二分句。优先级：Not only 只倒第一分句；第二分句按框架。
- 冲突：倒装 vs 强调 do。优先级：Not only 前置 → 倒装；无 Not only 的 do 只是强调。

**⑩ 自检清单**

- Not only 在句首吗？它触发的是部分倒装还是完全倒装？
- 原句有操作词吗？没有的话补 does 了吗？
- 操作词和主语倒装了吗（does he，不是 he does）？
- likes 还原成 like 了吗？
- 第二分句 but also listening 动了吗？
- 时态还是现在时吗？
- 两空是 does + he 吗？

### 三、冲突与优先级

| # | 冲突 | 谁优先 | 依据/题号 |
|---|---|---|---|
| 1 | 时态保持 vs 形式变换 | 时态保持优先 | 41 were allowed、42 didn't have、44 When do、45 did he 均因改时态出局 |
| 2 | 已有操作词 vs 补 do | 已有操作词优先 | 44 will 直接提前；45 无助动词才补 does；42 实义 have 补 does |
| 3 | there-be 的 be vs do-support | be 优先 | 43 Are there，不是 Do there |
| 4 | 实义 have vs 助动词 have | 先判身份，再定否定路径 | 42 实义 → doesn't have；助动词 → hasn't finished |
| 5 | 部分倒装 vs 完全倒装 | 看谓语类型与触发成分 | 44/45 走部分倒装（操作词 + 主语）；45 实义动词不直接倒装；43 的 be 前置是 there-be 疑问，不套部分/完全倒装二分 |
| 6 | 空数约束 vs 语法完整 | 语法完整优先，空数决定缩合/展开 | 42 两空取 doesn't；不能写 are allow 凑两空 |
| 7 | 指令范围 vs 原句其他部分 | 指令范围优先，其他部分冻结 | 41 不加冠词；44 不保留 next Sunday；45 不动第二分句 |
| 8 | 划线成分 vs 全句 | 只替换划线成分 | 44 只问 next Sunday，不问 They / the library |
| 9 | 直接疑问 vs 宾语从句 | 问号 + 主句 → 倒装；从句 → 陈述序 | 44 When will they go? 不是 When they will go? |
| 10 | Not only 第一分句 vs 第二分句 | 只倒第一分句 | 45 but also listening 按框架保留 |

总优先级链（做题时从上到下）：

1. 读指令，定“变什么”（被动/否定/疑问/倒装）。
2. 判谓语类型：be / 情态 / 助动词 / 实义动词 → 决定用 be 还是 do-support。
3. 定时态与人称：决定 be/do 的具体形式，锁定“不得改时态”。
4. 执行变换：提前、插入、删除、还原。
5. 管住范围：空外冻结；划线删除；第二分句不动。
6. 校验空数与书面规范：每空一词、缩合/展开、大小写、拼写、问号。

这条链的顺序不能反：先做形态再判谓语类型，必然出现 are allow / does he likes / Is there 这类“形态做了、身份没判”的错。
